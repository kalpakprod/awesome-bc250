# BC-250 README Visual System

## Purpose

- The audience is a new board owner or a reader evaluating community claims. The README keeps instructions and source limits in ordinary Markdown.
- The title uses existing board context, not benchmarks. The evidence flow is conceptual and does not imply a board test occurred.

## Tokens

- Paper is `#F8FAFC`, ink is `#172033`, and the focal accent is `#C2410C`. Neutral rules use `#CBD5E1` and secondary text uses `#475569`.
- SVGs use local system fonts with Cyrillic coverage; no remote font or image is loaded. Noto Sans and Georgia use platform fallbacks rather than requiring Geist or Instrument Serif.
- The evidence flow has three nodes and two vertical connectors. One check node receives the accent; no animation or shadow is used.
