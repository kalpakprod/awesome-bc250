## Scope

- The catalog documents the ecosystem, not just recommended installations. Experimental, archived, superseded and unsuccessful work remains discoverable with its limitations.
- Existence, relevance and runtime behavior are separate questions. An attributed project entry can be added without a local board test; a statement about stability, safety, performance or compatibility needs its own evidence.
- GitHub fork flags and revisions describe the dated snapshot. A similar name or identical README does not establish the same code, a parent relationship or independent corroboration.
- The original source corpus is dated 2026-09-29; the catalog organization was added in October 2026. The separate Reddit supplement was collected on 2026-10-07 through OpenTabs: 1275 distinct post records, 187 retrieved discussions and 3613 retrieved comments, with 22 selected discussions unavailable. An external project can have changed since either observation date.
- Unknown archived Discord threads, uninspected attachments, most new community-message contents and unindexed sources remain gaps. The catalog does not claim that every development has been found.

## Maintaining the catalog

- Add each distinct relevant project with a useful purpose description, canonical link, topic and documentation link when available. Keep meaningful forks and continuations separate; explain their relationship when supported by the source.
- Update the corresponding EN/RU/UK entries and public project records together. Do not replace a known revision with a guessed SHA or infer maintenance status from stars or a commit age alone.
- Keep unclassified search matches in the discovery inventory until their relationship to the board is established; unrelated matches should not inflate the project count.
- Keep message links rather than copying raw community text or attachments. Do not publish credentials, signed download URLs, private paths or access-bearing sharing identifiers.
- See [CONTRIBUTING.md](../CONTRIBUTING.md) for inclusion and correction rules. Existing documentation licensing applies to this catalog; linked projects retain their own licenses.
