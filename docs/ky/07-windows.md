# Windows Drivers & Setup

> **Кыскача** — **2026-нын башында BC-250 үчүн иштеген Windows GPU драйвери жок.** Windows орнотулат жана жүктөлөт, бирок GPU **Code 43** менен туруп калат жана 3D тездетүү такыр жок — даяр сатылган ар бир AMD драйверин (Adrenalin, Pro, W5700 `.inf` амалы) аппарат четке кагат. Коомчулук аны **нөлдөн тескери инженерия** менен курууда, чынчыл абал болсо: «алгачкы инфраструктура иштейт, бирок азырынча эч нерсе оюндарды чыгарбайт». Эгер бул тактаны бүгүн чындап *колдонгуңуз* келсе, **Linux орнотуңуз** ([06-linux.md](../en/06-linux.md)) — иштеген драйвер ошол жакта. Бул беттеги бардыгына шектенүү менен карап, ишенерден мурда репонун коммит даталарын текшериңиз.

Жаңы келгендерге 2025-тен бери бекитилген, эчак орногон коомчулук вердикти: *«Бул жакка киргендер, бардык үмүттөн баш тарткыла. Windows драйверлери 99.5% ыктымалдык менен болбойт. Драйверсиз бул такта дээрлик таптакыр пайдасыз. Linux драйвери бар — эгер сиз ал OS-ке даяр болбосоңуз, бул такта сизге керек эмес.»* ([src](https://t.me/c/2424231195/28109))

Бул бир жылдан ашык убакыт консенсус болуп келди. 2026-да ага **акыры каршы чыгууда** — бирок жайыраак, жана чынчыл жооп дагы эле ошондой: азырынча жок.

## Windows бул жерде эмне үчүн кыйын (Code 43 дубалы)

BC-250 APU («Cyan Skillfish» / Oberon, GFX10.1.3) OS-ке өзүн **белгисиз түзмөк** катары көрсөтөт — PCI ID `1002:13FE` — аны сатыкка чыккан бир да AMD драйвери таанышбайт. Адамдар бардыгын сынап көрүштү:

- Device Manager-ге **расмий `.inf`-ти күч менен таңуулоо**: Windows «шайкеш» катары сунган бирден-бир драйвер — **Radeon Pro W5700**. Ал орнотулат, анан **Error 43**-те туруп калат, сыналган башка ар бир драйвер сыяктуу эле. ([src](https://t.me/c/2424231195/57123))
- **`.inf`-ти оңдоо / түзмөк ID-лерин алмаштыруу** (gfx1013, 1014, Navi 21/22/23 «Dragonball», эски жазуулар), драйвердин кол коюусун текшерүүнү өчүрүү, атүгүл USB-дан Windows 10 жүктөп Steam Deck драйверин сынап көрүү — **бардыгы туюк жол**. Эски жазуулар катасыз көрүнгөнү дисплейдин бузугунан гана, иштегенинен эмес. ([src](https://t.me/c/2424231195/94029))
- Түзмөк ID-син өзгөртүү үчүн **BIOS-ту моддоо** да жардам берген жок — iGPU дагы эле `1002:13FE` деп билдирет. Dev ID **APU-га ширетилгендей** көрүнөт, жөн гана BIOS-ко эмес, ошондуктан бир жерди гана оңдоо жетишсиз. ([src](https://t.me/c/2424231195/57123))

Эмне үчүн Linux иштейт да Windows иштебейт? Linux-та ачык кодду **amdgpu/Mesa** стекин коомчулук дал ушул чипти таанытуу үчүн оңдогон (жана бир бөлүгүн upstream-ге кошкон); Windows-та оңдой турган ачык драйвер жок — AMD бул майнинг/сервер бөлүгү үчүн эч качан Windows драйверин чыгарган эмес, жабык Adrenalin/Pro стеги болсо белгисиз ID-ден баш тартат. ([src](https://t.me/c/2424231195/13210)) AMD-нын өз форумундагы «BC-250 drivers» темасы эч жакка жеткен жок. ([community.amd.com](https://community.amd.com/t5/pc-drivers-software/bc-250-drivers/td-p/671692))

> **GPU passthrough аркылуу качуу жолу да жок.** BC-250 өткөрүлгөн виртуалдык машинада (VM) Windows-ту иштетүү иштебейт: IOMMU passthrough жолу бул тактада бузук, жана бул *APU* (хост таза тапшырып бере турган өзүнчө карта эмес), жана чип башынан эле белгисиз түзмөк катары туура эмес аныкталат. ([src](https://t.me/c/2424231195/64772))

## Драйвердин учурдагы абалы — чынында эмне бар (2026-нын башына карата)

2025-тин аягында коомчулук AMD-ны күтүүнү токтотуп, аппаратты тескери инженерия менен **нөлдөн Windows драйверин куруп** баштады. Эки аракет маанилүү; экөө тең **эксперименталдык, иштеп жатат (WIP) жана азырынча оюндарды чыгарбайт.**

### Keshas-dev — нөлдөн жазылган WDDM драйвери (эң активдүү)

Эки шериктеш ядро режиминдеги драйвер, эң активдүү иштелип жаткан Windows аракети (бул жазылып жатканда **жалгыз PSP драйверинде ~56 коммит бар**):

- **[Keshas-dev/AMD-BC-250-PSP-Driver](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver)** — **PSP** (Platform Security Processor) үчүн төмөнкү деңгээлдеги драйвер. **Эмне иштейт:** ал жүктөлөт, **SOS firmware**-ди жүктөйт, BAR5 MMIO аркылуу аппараттык регистрлерди окуйт/жазат (GC, MMHUB, HDP, NBIO, DF блоктору), NBIO кулпусун ачат жана GPU драйвери үчүн регистр прокси катары иштейт. **Эмне иштебейт:** GPCOM ринг түзүү (SOS firmware TOS ринг протоколун колдобойт), ринг буфер аркылуу GPU-firmware жүктөө жана Trusted Memory Region инициализациясы. Башкача айтканда: ал чип менен сүйлөшө алат, бирок **азырынча графикалык кыймылдаткычты иштетип чыгара албайт.** ([repo](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver/commits/main/))
- **[Keshas-dev/AMD-BC-250-Windows-Driver](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver)** — шериктеш GPU драйвери. PSP драйвери менен бирдей сертификат/тест-кол коюу инфраструктурасын колдонот жана аны регистр көпүрөсү катары пайдаланат. Дагы эле эрте; пайдалуу 3D чыгаруу жок. ([repo](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver/commits/main/))

Тиричиликтин биринчи ачык белгиси — мүчөнүн 2025-жылдын октябрында **«менин биринчи иштеген драйверим (OpenGL 1.1)»** деп билдиргени болду ([src](https://t.me/c/2424231195/83320)) — атайылап белгиленди, анткени Code 43 менен өткөн бир жылдан кийин араң иштеген драйвердин *орнотулуп жана иштеши* да чыныгы белес эле: *«эгер бул драйвер чындап орнотулуп иштесе (жаман болсо да) — бул эбегейсиз чоң кадам.»* ([src](https://t.me/c/2424231195/83332)) Ошол толкундан чыккан драйвер дампы, `AMD Radeon BC-250 (Cyan Skillfish) driver 00.00.01.7z`, чатта бөлүшүлдү/бекитилди. ([src](https://t.me/c/2424231195/83322)) **Мындай эрте дамптын баарын эксперименталдык катары караңыз — `00.00.01` версиясы угулуп тургандай эле чийки.**

### ZEROAESQUERDA — WDDM 2.0 шилтеме ишке ашыруусу

**[ZEROAESQUERDA/BC250-windowsDriverTest](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest)** — өзүнчө аракет («португалиялык жигит бирдеме баштады»), 2026-жылдын мартында чатта муздун жарыла башташынын белгиси катары бекитилди. ([src](https://t.me/c/2424231195/123644)) Аны эң туура түшүнгөн — бул пайдалуу драйвер эмес, **шилтеме/окуу үчүн WDDM 2.0 ишке ашыруусу**:

- Бир гана **Direct3D 9 DDI**-ни ишке ашырат; **D3D11, D3D12 жана Vulkan ишке ашырылган эмес.**
- **RDNA2 (GFX10.1 ISA) үчүн шейдер компиляциясы иштебейт** — ал шейдер тапшырмаларын кабыл алат, бирок аларды чыныгы аппарат үчүн компиляциялай албайт, ошондуктан эч нерсе чыгарылбайт.
- Command Processor микрокодун **жүктөбөйт** (BIOS жүктөгөн firmware-ге таянат); **VCN видео кодер/декодер колдоого алынбайт**; бир гана DisplayPort чыгаруу.
- **Тест-кол коюу режимин** талап кылат (WHQL кол коюусу жок). main-де болгону ~2 коммит.

Ага убакыт коротордон мурда долбоордун өзүнүн **[Белгилүү чектөөлөр](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest?tab=readme-ov-file#15-limita%C3%A7%C3%B5es-conhecidas)** бөлүмүн караңыз.

> ⚠ **Репо аталышын оңдоо.** Негизги репо тизмеси «Drivers → Windows» астында `ZEROAESQUERDA/PS5GPU-BC250`-ге шилтейт. Текшерилгенде ал репо — **Linux GPU governor** (GUI менен Oberon-governor форку), Windows драйвери **эмес**. Бул автордун чыныгы Windows коду — **`BC250-windowsDriverTest`**.

## Эгер дагы эле WIP драйверлерин сынагыңыз келсе

Бул иштеген рабочий стол алуу үчүн эмес, **тестирлөөгө жардам бергиси** келген тинкерлер үчүн. Сизге керек болот:

- **Windows 10 (build 1607+) же Windows 11, x64.**
- **Тест-кол коюу күйгүзүлгөн** жана **Secure Boot өчүрүлгөн** (бул драйверлер кол коюлбаган/тест-кол коюлган):
  ```
  bcdedit /set testsigning on
  ```
  Кайра жүктөңүз. ⚠ текшериңиз — так кадамдар ар бир репонун README-синде; бул жердеги командалар стандарттык WDK тест-кол коюу агымы, долбоордун скриптинен көчүрүлгөн эмес.
- Репо берген **PowerShell скрипти** аркылуу (мисалы `Install-Driver.ps1`) же кол менен `pnputil` менен орнотуңуз. Бул бетти эмес, **репо README**-син ээрчиңиз — бул долбоорлор тез өзгөрөт жана орнотуу кадамдары алар менен кошо жылат.

Күтсө болот: эң жакшы учурда түзмөк эсептелип, алгачкы инициализация логдору пайда болот; эң начарында — эч нерсе өзгөрбөйт же башка ката коду чыгат. **Сизге кымбат болгондун баарын камдап коюңуз жана ал чыгарбайт деп эсептеңиз.**

### ⚠ Текшерилбеген уламыш: «драйверлерди агыткан такта „кирпич“ болот»

2025-тин башындагы бета-тест фазасында бир мүчө **BC-250-лер чыга элек драйверлерди агыткандыгы үчүн алыстан „кирпич“ кылынып жатат** деп эскерткен — Reddit-те «кирпич» болуу, түзмөктү алыстан бөгөттөө тууралуу билдирүүлөр бар, атүгүл аппараттык программатор да аларды ача алган жок дегендей. ([src](https://t.me/c/2424231195/26231)) **Биз муну текшере албадык**, жана анын тегерегиндеги бүт «жабык бета» баяндоосу шектүү (кийинки бөлүмдү караңыз). Толуктук үчүн айтылды; аны орногон чындык катары кабылдабаңыз. Эгер тактаны байланышы жок себептерден улам «кирпич» кылсаңыз, калыбына келтирүү үчүн [08-bios.md](../en/08-bios.md) караңыз.

## Калптар, тамашалар жана туюк жолдор — буларга алданбаңыз

BC-250-деги Windows-драйвер ызы-чуусунун **приколдордун жана кыял-чабыттын** узак тарыхы бар. Аптаны бекерге коротпош үчүн атактууларын билиңиз:

- **«AMD BC-250 үчүн NVIDIA драйвери».** **1-апрель алдамчылык күнү (1 апрель 2026)** тамашасы — кооз жасалган калп «NVIDIA NEW DRIVER RELEASE … for AMD BC-250» баннери кыска убакытка адамдарды *«NVIDIA чындап BC-250 үчүн Windows драйверин чыгардыбы?!»* деп сурадырды. ([src](https://t.me/c/2424231195/130053)) Чыгарган жок. NVIDIA AMD APU-су үчүн драйвер жасабайт. Чаттагы реакция *«узак күтүлгөн тамаша келди»* эле. ([src](https://t.me/c/2424231195/130727)) Ошондой эле `whql-amd-software-adrenalin-edition-25.5.1-...-bc250.exe` сыяктуу аталган `.exe` тарап жүргөнүн белгилеңиз — файл атына «bc250» жабыштырылган кадимки Adrenalin орноткуч аны BC-250 драйвери **кылбайт**. ([src](https://t.me/c/2424231195/73924))
- **«Жөн гана окшош картанын драйверин күч менен орнот».** RX 6700 / W5700 / Radeon Pro V340 — ар бир жаңы келгендин биринчи ою, жана ал *«BC-250 кармаган ар бир акмактын»* башына келген. Ал иштей албайт, кайра чыгарууга татыбаган себептердин жыйындысынан улам: **BC-250-де Windows драйверлери да, ар-намыс да, сыра да жок.** ([src](https://t.me/c/2424231195/29710))
- **Каналдагы зыяндуу программа.** Адамдар вирус/зип-бомба/фишер болгон калп «драйверлерди» жайгаштырышкан. Модераторлор көргөн жерден бан кылышат; бир жолу так `Trojan.txt` деп аталган файл пайда болгон. ([src](https://t.me/c/2424231195/49668)) **Бинарларды бир гана аталган GitHub репосунан иштетиңиз жана кодду окуп чыгыңыз.**

## Адамдар айтып жүргөн 40-CU кулпу ачуу скрипти жөнүндө эмне дейсиз?

`git clone https://github.com/duggasco/bc250-40cu-unlock.git` Windows темасындагы сүйлөшүүдө кездешет, ал тургай башкы ресурс тизмеси да аны «Windows» астында тэгдейт. **Бул — Linux `amdgpu` ядро патчи / скрипти** (`bc250-enable-40cu.sh`), Windows куралы эмес — ал Linux драйверинде бардык 40 CU-ну ачат. Ал [09-overclock-undervolt.md](../en/09-overclock-undervolt.md) ичинде туура каралган; Windows үчүн эч нерсе кылбайт. ⚠ текшериңиз (Command корпусундагы эч бир shell тарыхы анын Windows-та колдонулушун ырастабайт; жазылып калган бирден-бир команда — жогорудагы жөнөкөй `git clone`).
