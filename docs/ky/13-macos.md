# macOS / Hackintosh

> **Кыскача** — **Кылба.** Сиз балким macOS'ту BC-250'дин CPU'сунда жүктөй аласыз (бул Zen 2 AMD чиби, жана жалпы AMD-OSX hackintosh амалдары иштейт), бирок **GPU тездетпейт** жана аны иштетүүнүн реалдуу жолу жок. macOS GPU'ларды катуу жазылган түзмөк ID боюнча колдойт; BC-250'дин GPU'су (Cyan Skillfish / Oberon, кыскартылган PS5 бөлүгү) **анын ордуна өзүн көрсөтө турган, кутудан колдоого алынган үстөл эгизи жок**, жана Apple'дин стеги *эч качан* эч бир AMD APU'нун интеграцияланган графикасын башкарууга ылайыкталган эмес. Демек, сиз Metal'сыз, жай, программалык рендеринг кылган Mac аласыз. 2026-нын абалы боюнча, коомчулукта эч ким иштеген тездетилген натыйжаны билдирген эмес. Анын ордуна Linux колдонуңуз — [06-linux.md](../en/06-linux.md) караңыз.

Бул — реалдуу колдонуу учуру эмес, **тар кызыгуу**. Чынчыл жооп — бул бөлүмдүн өзү толугу менен.

## GPU тездетүү эмне үчүн дубал

Темадагы эң көп реакция алган эки техникалык посттун экөө тең бир эле жыйынтыкка келет, жана алар механизмди ачык түшүндүрөт.

macOS'та Linux сыяктуу ачык драйвер модели жок. Ал белгилүү бир GPU'ларга **түзмөк ID боюнча** байланышкан жабык драйверлерди жөнөтөт, жана сиз кийлигише ала турган бирден-бир жер — OS жүктөлгөнгө *чейинки* **OpenCore** жүктөгүчү — OpenCore macOS'ка алдын ала даярдалган маалыматты берет, жабык системаны анын ичинен оңдой албайт ([src](https://t.me/c/2424231195/103173)).

OpenCore GPU'нун түзмөк ID'син алмаштыра *алат*, бирок **бир архитектуралык үй-бүлөнүн ичинде** гана — мисалы, колдоого алынбаган RX 6950 XT'ни колдоого алынган RX 6900 XT катары көрсөтүү, анткени алар *бирдей* кремний. Бул амал OpenCore иштеп чыгуучуларынан **бир жылдан ашык** убакыт алган жана иштеген себеби — ал Navi карталары Apple буга чейин колдогон карталар менен архитектуралык жактан бирдей болгондуктан гана ([src](https://t.me/c/2424231195/53321)).

BC-250 муну эки жол менен бузат:

1. **Алмашуу үчүн эгиз жок.** Анын GPU'су — кыскартылган, PS5'тен алынган бөлүк (`gfx1013`). **macOS кутудан колдогон, бирдей архитектурадагы үстөл AMD картасы жок**, ошондуктан өзүн ага окшоштурарга эч нерсе жок. BC-250 иштеши үчүн Apple'дин стеги бул түзмөк ID'син нөлдөн үйрөнүшү керек болор эле — бул болсо OpenCore иштеп чыгуучулары чипти колго алса гана болот, ага коммерциялык себеп жок ([src](https://t.me/c/2424231195/53321)).
2. **Бул — APU, ал эми APU'лар эч качан иштеген эмес.** Атүгүл үстөл архитектурасындагы Ryzen интеграцияланган графикасы (Vega / Navi iGPU'лар) macOS'та **эч качан** иштетилген эмес, колдоого алынган бөлөк карталар менен микроархитектураны бөлүшсө да. Автор macOS'та иштеген Ryzen iGPU'нун «бир да учурун көргөн эмес» ([src](https://t.me/c/2424231195/103173)). BC-250 ошол эле APU чакасында.

Дал ошол салымчынын ачык жыйынтыгы: *эгер бул чип үчүн Windows драйверлери да чечилбесе, macOS жөнүндө кыялданып да отурганга татыбайт* ([src](https://t.me/c/2424231195/53321)). (Windows драйверинин абалы жөнүндө [07-windows.md](../en/07-windows.md) караңыз.)

## Адамдар чындап эмнени сынашты

- Бирөө башында **macOS Monterey recovery + OpenCore** пакетин даярдап, бөлүшкөн (`Monterey recovery + OpenCore.zip`, плюс мурунку `Архив.zip`), демек жок дегенде бир киши аны орнотууга киришкен ([src](https://t.me/c/2424231195/53590)). Тездетилген GPU ийгилиги жөнүндө эч качан кабар келген эмес.
- Адамдар көрсөткөн тиешелүү аспаптар — стандарттык AMD-hackintosh топтому: түзмөк ID'син жасалмалоо [RehabMan/OS-X-Fake-PCI-ID](https://github.com/RehabMan/OS-X-Fake-PCI-ID) аркылуу, чындап эмне колдоого алынганы боюнча [Dortania AMD GPU buyers guide](https://dortania.github.io/GPU-Buyers-Guide/modern-gpus/amd-gpu.html#navi-10-series), жана — APU графикасын колдоого эң жакын нерсе — AMD APU iGPU'лары үчүн kext болгон **[ChefKissInc/NootedRed](https://github.com/ChefKissInc/NootedRed)**. NootedRed Vega/Renoir классындагы APU'ларга багытталган жана BC-250'дин кристаллын **камтыбайт**, ошондуктан бул такта аны куткарбайт.
- [VMware/OpenCore аркылуу AMD Ryzen'де macOS иштетүү](https://forum.amd-osx.com/threads/mac-os-install-on-amd-ryzen-intel-vmware-opencore-improved-performance-works-with-tahoe-sequoia-sonoma-etc.4696/) жөнүндө кийинки форум шилтемеси ([src](https://t.me/c/2424231195/107779)) — **жалпы AMD hackintosh**, BC-250'ге тиешелүү эмес — жана VM дегени баары бир GPU passthrough/Metal жок дегенди билдирет.

> ⚠ **Тамашаларды натыйжа менен чаташтырба.** Темада жеңил «сонун, кудуреттүү hackintosh бул жакта эрежелейт» деген тамаша ([src](https://t.me/c/2424231195/85166)) жана мактоо реакциялары бар, бирок алар иштеген macOS курулушунун *кабары* эмес. Далилдердин эч биринде BC-250'де тездетилген macOS көрсөтүлгөн эмес.

## Анда мунун мааниси барбы?

**Жок, кандайдыр бир практикалык максат үчүн.** Эң мыкты реалдуу натыйжа — UI'ди программалык түрдө рендеринг кылган, CPU'га гана таянган macOS — Metal жок, GPU эсептөө жок, бул такта сатылып алынган оюн/AI жүктөрү үчүн жараксыз. **2025-06**'дан **2026-03**'кө чейин даталанган жана өзгөрбөгөн коомчулук консенсусу: OpenCore иштеп чыгуучулары бул чипти атайын колго албаса, GPU колдоосу иш жүзүндө мүмкүн эмес, ал болсо болгон жок жана күтүлбөйт.

Эгер сиз бул тактанын бир нерсе *жасаганын* кааласаңыз, GPU чындап Mesa/RADV аркылуу колдоого алынган Linux орнотуңуз ([06-linux.md](../en/06-linux.md)). Windows — алыс экинчи орунда ([07-windows.md](../en/07-windows.md)). macOS — акыркы, жана иш жүзүндө туюк жол.
