# WiFi- и Bluetooth-донглы

> **Коротко** — На BC-250 **нет встроенного WiFi и Bluetooth**, поэтому нужен USB-донгл. Самый надёжный выбор по чату — свисток на **aic8800d80** (например, *AX90BT / D80MU3*) с драйвером [`shenmintao/aic8800d80`](https://github.com/shenmintao/aic8800d80): под Bazzite есть проверенный рецепт сборки RPM. Свистки на **Realtek RTL88xx** (8821au/cu, 8822bu, 8851bu) дёшевы и распространены, но это головная боль №1 в чате: подключаются, а потом **случайно отваливаются под нагрузкой**. [`lwfinger/rtw88`](https://github.com/lwfinger/rtw88) (бэкпорт драйвера) лечит большую часть проблем для семейства RTL8821/8822; свисткам RTL8851BU/8831BU «AX900 WiFi 6» нужен [`biglinux/rtl8831`](https://github.com/biglinux/rtl8831). Если хочется, чтобы заработало «из коробки», владельцы хвалят серию **Digma DWA-BT5**. Bluetooth делит радио 2,4 ГГц с WiFi, так что при активном BT скорость WiFi проседает.

Если интернет нужен только для установки, **проводной USB-Ethernet или встроенный сетевой порт** полностью обходят эту страницу. Донгл WiFi/BT берите, когда реально нужна беспроводная сеть или Bluetooth-геймпад.

## Что нужно понять в первую очередь

Почти каждая жалоба «донгл постоянно отваливается» на BC-250 сводится к **двум вещам, а не к надписи на коробке**:

1. **Чипсет внутри.** Бренд (ASUS, TP-Link, D-Link…) ничего не значит — важен чип Realtek/aic/MediaTek под корпусом. Три свистка разных марок могут нести один и тот же чип и отваливаться одинаково. ([src](https://t.me/c/2424231195/16332))
2. **Питание/стабильность USB под нагрузкой.** У многих свисток работает в простое/при сёрфинге и **отваливается, как только трафик скачет** (большая закачка), «как будто USB не хватает». У одного человека ASUS-свисток продержался ровно 17 минут и отвалился на скачивании. ([src](https://t.me/c/2424231195/16331)) · ([src](https://t.me/c/2424231195/17319))

Итого: **выбирайте по чипсету**, подбирайте под него поддерживаемый внешний драйвер, и если всё равно отваливается — лечите как проблему питания/сброса (см. [Отвалы](#борьба-со-случайными-отвалами) ниже).

> **Как узнать чипсет?** На коробке его почти никогда не пишут. Перед покупкой пробейте **FCC ID** свистка (он на устройстве/в объявлении) онлайн — в заявке виден реальный чип. А когда воткнёте его, выполните на Linux **`lsusb`**, чтобы увидеть ID производителя/устройства и чипсет.

## Путь A — aic8800d80 (рекомендуется)

Это чип с самой чистой историей на BC-250. Есть полный рецепт RPM под Bazzite и написанный сообществом мини-гайд.

### Bazzite (rpm-ostree) — сборка RPM

В [`bazzite/README.md`](https://github.com/shenmintao/aic8800d80/blob/main/bazzite/README.md) собирается нормальный RPM, чтобы драйвер лучше переживал обновления образа, чем сырой `make`. Сверено с репозиторием:

```bash
# 1. Зависимости для сборки (потом перезагрузка, чтобы оверлей применился)
sudo rpm-ostree install rpm-build rpmdevtools dkms
sudo systemctl reboot

# 2. Готовим дерево rpmbuild и забираем spec
cd "$HOME"
rpmdev-setuptree
cd "$HOME/rpmbuild/SPECS"
curl -LO -s https://raw.githubusercontent.com/shenmintao/aic8800d80/refs/heads/main/bazzite/aic8800d80.spec

# 3. Тянем исходники и собираем
spectool -g -R "$HOME/rpmbuild/SPECS/aic8800d80.spec"
rpmbuild -bs "$HOME/rpmbuild/SPECS/aic8800d80.spec"
sudo rpm-ostree usroverlay
rpmbuild --define "uname $(uname -r)" -bb "$HOME/rpmbuild/SPECS/aic8800d80.spec"

# 4. Ставим собранный RPM и перезагружаемся (имя файла зависит от версии ядра/fedora)
sudo rpm-ostree install "$HOME"/rpmbuild/RPMS/x86_64/aic8800d80-*.rpm
sudo systemctl reboot
```

Участник чата ([Nurmukhamed](https://github.com/Nurmukhamed/aic8800d80/tree/15a927286788af46529909bc2c14d16ea4241ec0/bazzite)) написал инструкцию по упаковке RPM, за что сообщество его поблагодарило. ([src](https://t.me/c/2424231195/122580))

### Мини-гайд сообщества (быстрый путь через «make»)

Если нужно поднять *прямо сейчас* и не лень перезапускать после ребутов — гайд Aqtilek ([src](https://t.me/c/2424231195/120502)):

```bash
# Свисток сначала видится как фейковый CD-ROM. Переключаем его в режим WiFi (ОДИН РАЗ):
sudo sh install_setup.sh         # теперь виден как "aic device wlan"

# Временно снимаем read-only с корня (Bazzite/atomic):
sudo rpm-ostree usroverlay

# Клонируем и собираем драйвер (используем «второй метод» из репозитория):
git clone https://github.com/shenmintao/aic8800d80.git && cd aic8800d80
# …дальше второй способ установки из репозитория.
```

> ⚠ **Сохранность после перезагрузки:** при пути через сырой `make` **драйвер слетает при каждой перезагрузке** и его надо переустанавливать — автор советует небольшой скрипт автозапуска. ([src](https://t.me/c/2424231195/120502)) Путь через RPM выше — это надёжное решение.

Архив с прошивкой/драйвером, которым пользовался участник (*AX90BT(D80MU3)*), выкладывали в чат. ([src](https://t.me/c/2424231195/119991)) Есть альтернативный апстрим [`goecho/aic8800_linux_drvier`](https://github.com/goecho/aic8800_linux_drvier), но один пользователь CachyOS просидел 6 часов и не смог его собрать — на BC-250 предпочитайте `shenmintao`. ([src](https://t.me/c/2424231195/82100)) ⚠ проверьте под свой дистрибутив.

## Путь B — Realtek RTL8821 / RTL8822 (rtw88)

Дёшево и повсюду, но ядерный драйвер на старых ядрах **глючный и случайно отваливается**. Лечение — бэкпорт внешнего драйвера `lwfinger/rtw88`. Точные команды, которыми воспользовался участник и подтвердил стабильность ([src](https://t.me/c/2424231195/16326)):

```bash
git clone https://github.com/lwfinger/rtw88
cd rtw88
make
sudo make install
sudo make install_fw
```

При Secure Boot / DKMS в репозитории также описан путь `sudo dkms install $PWD` + `mokutil` — см. [README репозитория](https://github.com/lwfinger/rtw88).

**Почему помогает:** отвалы — это известный баг драйвера; нормальное исправление попало в mainline только в **ядрах 6.13–6.14**, а многие образы дистрибутивов всё ещё везли сломанную версию. Бэкпорт lwfinger даёт исправленный драйвер уже сейчас. ([src](https://t.me/c/2424231195/17321)) Из USB-чипов поддерживаются RTL8811AU/CU, RTL8812AU/BU/CU, RTL8814AU, RTL8821AU/CU и RTL8822BU/CU (полный список — в репозитории).

> Честная оговорка: даже с rtw88 один пользователь на RTL8821cu видел редкие отвалы («та же шляпа»), а скорость немного ниже, чем у сломанного-но-быстрого стокового драйвера. ([src](https://t.me/c/2424231195/16333)) Если надёжность важнее цены — берите aic8800d80 или проверенную Digma.

## Путь C — Realtek RTL8851BU / RTL8831BU («AX900 WiFi 6»)

Совсем дешёвые свистки «AX900 WiFi 6 + Bluetooth 5.3» используют **RTL8851BU/8831BU**, который `rtw88` **не** поддерживает, так что из коробки они мёртвые. ([src](https://t.me/c/2424231195/17320)) Берите отдельный драйвер [`biglinux/rtl8831`](https://github.com/biglinux/rtl8831):

```bash
git clone https://github.com/biglinux/rtl8831
cd rtl8831
sudo dkms install .        # или: make && sudo make install
sudo modprobe 8851bu
```

⚠ проверьте — сборку этого репозитория именно на BC-250 в чате не показывали; команды взяты из README репозитория.

## Борьба со случайными отвалами

Если свисток подключается и потом отваливается (классический симптом Realtek на BC-250):

1. **Поставьте правильный внешний драйвер** (Путь B/C) — это решает большинство случаев.
2. **Передёрните после загрузки.** Некоторые свистки не определяются при холодном старте, помогает одно «вынул-вставил». ([src](https://t.me/c/2424231195/16325))
3. **Сбросьте устройство программно вместо передёргивания** — используйте `usbreset` (физически вынимать не нужно). ([src](https://t.me/c/2424231195/135895)) · [как (Superuser)](https://superuser.com/questions/141908/how-do-i-reset-an-usb-device-without-unplugging-it-in-linux)
4. **Попробуйте другой USB-порт** (лучше задний/корневого хаба) — симптом похож на нехватку питания/полосы под нагрузкой. ([src](https://t.me/c/2424231195/17319))

## Про Bluetooth

- Комбо-свистки WiFi+BT делят радио **2,4 ГГц**, поэтому **скорость WiFi падает при активном Bluetooth**. Один участник намерил **~150 Мбит с включённым BT против ~190 Мбит без него** — реально, но «не так драматично». ([src](https://t.me/c/2424231195/123366)) · ([src](https://t.me/c/2424231195/123367))
- У драйвера aic8800d80 есть **отдельная ветка `bluetooth`** для поддержки BT. ([ветка репозитория](https://github.com/shenmintao/aic8800d80/tree/bluetooth?tab=readme-ov-file))

## Что покупать (короткий список)

Если хочется наименьшего риска, по порядку:

1. **Свисток на aic8800d80** (класса AX90BT / D80MU3) + рецепт RPM под Bazzite — лучше всего задокументирован, WiFi+BT.
2. **Digma DWA-BT5-AC600C / AC1300E** — по отзывам работает из коробки. ([Ozon](https://www.ozon.ru/product/setevoy-adapter-wifi-bluetooth-digma-dwa-bt5-ac600c-dvuhdiapazonnyy-1689608277/))
3. **Свисток RTL8821CU + lwfinger/rtw88** — самый дешёвый, миритесь с редкими отвалами.
4. Избегайте копеечных **RTL8851BU «AX900»**, если не готовы возиться с `biglinux/rtl8831`.

> Не верьте ИИ-боту с его «да, бро, идеальный выбор» по поводу донгла — участник так и сделал, получил RTL8822BU, который отваливается каждые 5–10 мин, а тот же бот потом сказал, что работать не будет. Покупайте по чипсету, проверенному здесь. ([src](https://t.me/c/2424231195/138512))
