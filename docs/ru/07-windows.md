# Драйверы и настройка Windows

> **TL;DR** — На **начало 2026 года рабочего GPU-драйвера под Windows для BC-250 не существует.** Windows ставится и грузится, но видеокарта висит с **ошибкой Code 43** и без какого-либо 3D-ускорения — любой готовый драйвер AMD (Adrenalin, Pro, трюк с `.inf` от W5700) железо отвергает. Сообщество **пишет драйвер с нуля методом реверс-инжиниринга**, и честное состояние дел — «ранняя обвязка частично работает, но игры ничего не рисуют». Если хотите реально *пользоваться* платой сегодня — **ставьте Linux** ([06-linux.md](06-linux.md)): рабочий драйвер живёт именно там. Ко всему на этой странице относитесь скептически и сверяйте даты коммитов в репозиториях, прежде чем чему-то верить.

Давний вердикт сообщества, закреплённый для новичков ещё с 2025 года: *«Оставь надежду, всяк сюда входящий. Дров на Windows не будет с вероятностью 99,5%. Без драйвера эта железка бесполезна чуть более, чем полностью. Однако драйвер есть на Linux — если ты не готов к этой ОС, тебе не нужна эта железка».* ([src](https://t.me/c/2424231195/28109))

Это был консенсус больше года. В 2026-м его **наконец начали оспаривать** — но медленно, и честный ответ по-прежнему: пока нет.

## Почему Windows здесь — это боль (стена Code 43)

APU BC-250 («Cyan Skillfish» / Oberon, GFX10.1.3) представляется системе как **неизвестное устройство** — PCI ID `1002:13FE`, — которое не опознаёт ни один существующий драйвер AMD. Перепробовали уже всё:

- **Насильно скормить официальный `.inf`** диспетчеру устройств: единственный драйвер, который Windows предлагает как «совместимый», — **Radeon Pro W5700**. Он ставится, но виснет на **ошибке 43**, ровно как и все остальные. ([src](https://t.me/c/2424231195/57123))
- **Правка `.inf` / подмена device ID** (gfx1013, 1014, Navi 21/22/23 «драгонболлы», legacy-записи), отключение проверки подписи драйверов, запуск Windows 10 с USB, попытка драйвера от Steam Deck — **всё в тупик**. Legacy-записи отображаются без ошибки только из-за бага отображения, а не потому что работают. ([src](https://t.me/c/2424231195/94029))
- **Моддинг BIOS** для смены device ID тоже не помог — iGPU всё равно определяется как `1002:13FE`. Похоже, Dev ID **намертво закреплён за самим APU**, а не только за BIOS, поэтому правки в одном месте мало. ([src](https://t.me/c/2424231195/57123))

Почему на Linux работает, а на Windows нет? На Linux открытый стек **amdgpu/Mesa** был допилен сообществом (и частично принят в апстрим) под этот конкретный чип; на Windows допиливать нечего — AMD никогда не выпускала Windows-драйвер для этой майнинг/серверной железки, а закрытый стек Adrenalin/Pro отказывается принимать неизвестный ID. ([src](https://t.me/c/2424231195/13210)) Собственная ветка на форуме AMD про «драйверы BC-250» ни к чему не привела. ([community.amd.com](https://community.amd.com/t5/pc-drivers-software/bc-250-drivers/td-p/671692))

> **Лазейки через проброс GPU тоже нет.** Запустить Windows в виртуалке с проброшенным BC-250 не выйдет: путь проброса через IOMMU на этой плате сломан, это *APU* (а не дискретная карта, которую хост может чисто отдать), и сам чип изначально определяется как неизвестное устройство. ([src](https://t.me/c/2424231195/64772))

## Текущий статус драйверов — что реально существует (на начало 2026)

В конце 2025-го сообщество перестало ждать AMD и начало **писать Windows-драйвер с нуля**, реверся железо. Значимых усилий два, и оба — **экспериментальные, в разработке, игры пока не рисуют.**

### Keshas-dev — драйвер WDDM с нуля (самый активный)

Пара парных kernel-mode драйверов, наиболее активно развиваемая Windows-разработка (только у **PSP-драйвера ~56 коммитов** на момент написания):

- **[Keshas-dev/AMD-BC-250-PSP-Driver](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver)** — низкоуровневый драйвер для **PSP** (Platform Security Processor). **Что работает:** грузится, поднимает **прошивку SOS**, читает/пишет регистры железа через BAR5 MMIO (блоки GC, MMHUB, HDP, NBIO, DF), делает NBIO-разлок и работает прокси-мостом для GPU-драйвера. **Что не работает:** создание кольца GPCOM (прошивка SOS не поддерживает протокол TOS ring), загрузка прошивки GPU через ring buffer и инициализация Trusted Memory Region. То есть: с чипом он говорить умеет, но **поднять графический движок пока не может.** ([repo](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver/commits/main/))
- **[Keshas-dev/AMD-BC-250-Windows-Driver](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver)** — парный GPU-драйвер. Использует ту же инфраструктуру сертификатов / тестовой подписи, что и PSP-драйвер, и опирается на него как на мост к регистрам. Пока ранняя стадия; рабочего 3D-вывода нет. ([repo](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver/commits/main/))

Первый публичный признак жизни — сообщение участника **«мой первый рабочий драйвер (OpenGL 1.1)»** в октябре 2025 ([src](https://t.me/c/2424231195/83320)) — праздновали именно потому, что даже едва работающий драйвер, который *ставится и запускается*, был настоящей вехой после года Code 43: *«если этот драйвер реально поставился и работает (пускай и хуёво) — это ебать какой прогресс».* ([src](https://t.me/c/2424231195/83332)) Дамп драйвера из той волны, `AMD Radeon BC-250 (Cyan Skillfish) driver 00.00.01.7z`, был выложен/закреплён в чате. ([src](https://t.me/c/2424231195/83322)) **Любой такой ранний дамп считайте экспериментальным — версия `00.00.01` ровно настолько сырая, как и звучит.**

### ZEROAESQUERDA — эталонная реализация WDDM 2.0

**[ZEROAESQUERDA/BC250-windowsDriverTest](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest)** — отдельная разработка («португал что-то начал»), закреплена в чате в марте 2026 как знак того, что лёд тронулся. ([src](https://t.me/c/2424231195/123644)) Её лучше воспринимать как **референсную/учебную реализацию WDDM 2.0**, а не как рабочий драйвер:

- Реализован только **DDI Direct3D 9**; **D3D11, D3D12 и Vulkan не реализованы.**
- **Компиляция шейдеров под RDNA2 (ISA GFX10.1) не работает** — драйвер принимает шейдеры, но не может скомпилировать их под реальное железо, поэтому ничего не рендерится.
- **Не** грузит микрокод Command Processor (полагается на прошивку из BIOS); **видео-кодирование/декодирование VCN не поддерживается**; только один выход DisplayPort.
- Требует **режим тестовой подписи** (подписи WHQL нет). В ветке main всего ~2 коммита.

Перед тем как тратить на него время, прочтите собственный раздел проекта **[Известные ограничения](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest?tab=readme-ov-file#15-limita%C3%A7%C3%B5es-conhecidas)**.

> ⚠ **Поправка по названию репозитория.** В основном списке ресурсов в разделе «Drivers → Windows» указан `ZEROAESQUERDA/PS5GPU-BC250`. При проверке оказалось, что этот репозиторий — **Linux-губернатор GPU** (форк oberon-governor с GUI), **а не** Windows-драйвер. Реальный Windows-код этого автора — **`BC250-windowsDriverTest`**.

### Статус одним взглядом

| Проект | Тип | Что работает | Что не работает | Использовать сегодня? |
|---|---|---|---|---|
| Keshas-dev/AMD-BC-250-PSP-Driver | Kernel-драйвер PSP (WIP) | Поднимает прошивку SOS, R/W регистров BAR5, NBIO-разлок, прокси регистров | Создание кольца GPU, загрузка прошивки, инициализация TMR | Нет — только обвязка |
| Keshas-dev/AMD-BC-250-Windows-Driver | GPU-драйвер (WIP) | Грузится рядом с PSP-драйвером | Рабочего 3D нет | Нет |
| ZEROAESQUERDA/BC250-windowsDriverTest | Референс WDDM 2.0 | Каркас драйвер-модели, есть DDI D3D9 | Компиляция шейдеров, D3D11/12, Vulkan, VCN | Нет — учебный |
| Adrenalin / Pro / `.inf` от W5700 | Официальный AMD | — | **Code 43**, ничего | Нет |

**Итог:** на Windows на BC-250 сегодня в игры не играет никто. Работа реальная и ускоряется, но она на стадии «получится ли вообще инициализировать GPU», а не «сколько у меня FPS в Cyberpunk».

## Если всё же хотите попробовать WIP-драйверы

Это для энтузиастов, которые хотят **помочь с тестами**, а не получить рабочий рабочий стол. Понадобится:

- **Windows 10 (сборка 1607+) или Windows 11, x64.**
- **Включённая тестовая подпись** и **отключённый Secure Boot** (драйверы неподписанные / с тестовой подписью):
  ```
  bcdedit /set testsigning on
  ```
  Перезагрузка. ⚠ verify — точные шаги смотрите в README каждого репозитория; команда здесь — стандартный порядок тестовой подписи WDK, а не скопированная из скрипта проекта.
- Установка через предоставляемый репозиторием **PowerShell-скрипт** (например, `Install-Driver.ps1`) или вручную через `pnputil`. Следуйте **README репозитория**, а не этой странице — проекты меняются быстро, и шаги установки меняются вместе с ними.

Ожидайте: в лучшем случае устройство определится и появятся ранние логи инициализации; в худшем — ничего не изменится либо получите другой код ошибки. **Сделайте бэкап всего важного и исходите из того, что рендерить оно не будет.**

### ⚠ Непроверенный слух: «слив драйверов кирпичит плату»

На ранней стадии бета-теста в начале 2025-го участник предупреждал, что **BC-250 удалённо превращают в кирпич за слив предрелизных драйверов**: ссылался на сообщения с Reddit об окирпичивании, удалённую блокировку устройств и на то, что даже программатором их не разлочить. ([src](https://t.me/c/2424231195/26231)) **Подтвердить это не удалось**, да и вся обёртка про «закрытую бету» вокруг этого сомнительна (см. следующий раздел). Упомянуто для полноты; за установленный факт не считать. Если окирпичили плату по другим причинам — про восстановление см. [08-bios.md](08-bios.md).

## Мистификации, шутки и тупики — не ведитесь

У хайпа вокруг Windows-драйвера на BC-250 долгая история **розыгрышей и принятия желаемого за действительное**. Знайте знаменитые, чтобы не угробить выходные:

- **«Драйвер NVIDIA для AMD BC-250».** Это **первоапрельская (1 апреля 2026) шутка** — красивый фейковый баннер «NVIDIA NEW DRIVER RELEASE … for AMD BC-250», из-за которого народ на минуту начал спрашивать *«реально, NVIDIA выпустила драйвера под BC-250 на виндовс?!»* ([src](https://t.me/c/2424231195/130053)) Нет. NVIDIA не делает драйверы для APU от AMD. Реакция в чате: *«рофлы дождались».* ([src](https://t.me/c/2424231195/130727)) Также гулял `.exe` с именем вроде `whql-amd-software-adrenalin-edition-25.5.1-...-bc250.exe` — обычный установщик Adrenalin с дописанным «bc250» в имени файла драйвером для BC-250 **не** становится. ([src](https://t.me/c/2424231195/73924))
- **«Просто поставь принудительно драйвер похожей карты».** RX 6700 / W5700 / Radeon Pro V340 — первая мысль каждого новичка, и она уже посетила *«каждого балбеса, которому в руки попала BC-250»*. Работать это не может по целой совокупности причин, которые незачем выводить заново: **на BC-250 нет Windows-драйверов, нет чести и нет пива.** ([src](https://t.me/c/2424231195/29710))
- **Вирусы в канале.** Под видом «драйверов» выкладывали вирусы / зип-бомбы / фишеры. Модераторы банят на месте; однажды появился файл, буквально названный `Trojan.txt`. ([src](https://t.me/c/2424231195/49668)) **Запускайте бинарники только из названных GitHub-репозиториев и читайте код.**

## А что за скрипт разблокировки 40 CU, который все упоминают?

`git clone https://github.com/duggasco/bc250-40cu-unlock.git` всплывает в обсуждениях Windows-темы, и в основном списке ресурсов он даже помечен как «Windows». **Это Linux-патч ядра / скрипт для `amdgpu`** (`bc250-enable-40cu.sh`), а не инструмент под Windows — он разблокирует все 40 CU на Linux-драйвере. Подробно он разобран в [09-overclock-undervolt.md](09-overclock-undervolt.md); для Windows он не делает ничего. ⚠ verify (история shell-команд из корпуса не подтверждает применение под Windows; единственная зафиксированная команда — это `git clone` выше).

## Рекомендация

| Если вам нужно… | Делайте так |
|---|---|
| Играть / реально пользоваться платой сейчас | **Ставьте Linux.** См. [06-linux.md](06-linux.md). Рабочий GPU-драйвер существует только там. |
| Следить за / помогать Windows-разработке | Следите за **Keshas-dev** (PSP + GPU-драйвер) и **ZEROAESQUERDA/BC250-windowsDriverTest**; ждите работы с ядром/WDK, а не игр. |
| Магический `.inf` или драйвер «похожей карты» | Его нет. Остановитесь — упрётесь только в Code 43. |

Поддержка Windows — **движущаяся мишень**: перед действиями пересматривайте даты коммитов в репозиториях и дату этого раздела (отражает **начало 2026**). Вердикт 2025-го был «никогда»; 2026-й понизил его до «пока нет» — реальный прогресс, но прогресс на уровне инициализации прошивки, а не играбельного рабочего стола.
