# macOS / Hackintosh

**Состояние на 7 октября 2026 года:** существует BC250-специфичный проект **MetalCyan** с заявленным ускорением Metal. Старый вывод этого справочника «GPU не заработает, пути нет» устарел. Для игровой консоли основной путь по-прежнему [Linux](06-linux.md); macOS — отдельная экспериментальная сборка с конкретной версией ОС.

## Проекты и что они делают

- [amethyst8118/MetalCyan](https://github.com/amethyst8118/MetalCyan) — плагин Lilu, адаптирующий закрытые драйверы Apple AMDRadeonX6000 к Cyan Skillfish. Это не простая подмена PCI ID. Проект начался как ответвление NootedRed.
- [amethyst8118/BC-250-Hackintosh-OpenCore](https://github.com/amethyst8118/BC-250-Hackintosh-OpenCore) — отдельный проект полной EFI-конфигурации.
- [Lilu](https://github.com/acidanthera/Lilu) — необходимая зависимость MetalCyan; загружается раньше него.

## Требования

По README MetalCyan, проверенному 7 октября 2026:

| Параметр | Требование |
|---|---|
| macOS | **Tahoe 26.7.1**; другие версии не заявлены поддержанными |
| SMBIOS | **MacPro7,1** |
| OpenCore | В описанной конфигурации **1.0.8** |
| UMA framebuffer | **4 ГБ** в BIOS; с 512 МБ автор сообщает зависания из-за нехватки памяти GPU |
| Lilu | **1.7 или новее**, до MetalCyan в порядке загрузки |
| Другие GPU kext | Не совмещать с WhateverGreen, NootedRed или NootRX |

Это требования конкретного драйвера, не универсальная рекомендация делить память BC250 так же в Linux. Не переносить настройки автоматически между ОС.

## Установка

1. Сохрани рабочую EFI целиком и запиши исходные настройки BIOS, особенно UMA. Оставь отдельный носитель, с которого можно загрузить прежнюю систему.
2. Подготовь OpenCore/AMD-конфигурацию для указанной версии macOS по EFI-проекту выше. Сам MetalCyan не заменяет загрузчик и весь набор AMD CPU-патчей.
3. Установи в BIOS UMA **4 ГБ**. Другие значения не входят в описанную автором конфигурацию.
4. Возьми `MetalCyan-1.0.1-RELEASE.zip` из [релиза MetalCyan](https://github.com/amethyst8118/MetalCyan/releases/tag/v1.0.1). Положи `MetalCyan.kext` в `EFI/OC/Kexts`.
5. Добавь его в `Kernel > Add` после Lilu и отключи другие GPU kext. Для этой EFI разработчик также указывает `npci=0x3000` в boot-args.
6. Загрузи macOS без экспериментальных частот и разблокировки. Проверь сначала рабочий стол и Metal-приложение, затем изменения по одному.

## Что проверить и какие ограничения остаются

Автор заявляет Metal 3, ускорение WindowServer/Safari/Firefox, 4K60, доступность выделенных 4 ГБ VRAM и телеметрию GPU. Здесь пересказана поддерживаемая конфигурация проекта, а не заявлен наш собственный тест платы.

- **VCN decode/encode не работает в этом драйвере**: видео декодируется программно.
- **DP/HDMI-звук не настроен.** Safari/TV могут отказываться воспроизводить видео без устройства вывода звука; нужен отдельный аудиовыход либо виртуальное устройство.
- **Восстановление зависшего GPU отсутствует**: потребуется перезагрузка.
- **Выключение/перезагрузка:** в README описана паника WindowServer при завершении; следующий запуск отдельно от этого.
- **Сон не протестирован.**

Смена macOS, SMBIOS или версии kext требует новой проверки совместимости. Наличие загрузочного аргумента для обхода проверки версии не означает поддержку новой ОС.

## Откат

`-MCOff` отключает MetalCyan и возвращает firmware framebuffer без ускорения. Для полного отката верни сохранённую EFI и прежние параметры BIOS. Если доступ к столу потерян, загрузи резервный носитель и восстанови EFI оттуда. Удаление kext не отменяет изменения BIOS или применённые настройки SMU.

## История исследований

До появления MetalCyan обсуждения предлагали Monterey/OpenCore и подмену device ID, но не давали подтверждённого пути BC250 Metal. Эти сообщения полезны как история, не как текущий запрет. NootedRed для других AMD APU также опровергает прежнее обобщение «AMD APU никогда не работали в macOS»; его поддержка сама по себе не является поддержкой BC250.
