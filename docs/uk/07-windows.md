# Драйвери та налаштування Windows

> **Коротко** — Станом на **початок 2026 робочого драйвера GPU під Windows для BC-250 не існує.** Windows встановлюється й завантажується, але GPU висить із **Code 43** і нульовим 3D-прискоренням — кожен готовий драйвер AMD (Adrenalin, Pro, трюк із `.inf` W5700) відхиляється залізом. Спільнота **реверс-інжинірить його з нуля**, і чесний стан — «рання обв'язка працює, ігри ще не рендеряться». Якщо ви хочете реально *користуватися* цією платою сьогодні — **встановіть Linux** ([06-linux.md](../en/06-linux.md)) — саме там живе робочий драйвер. Сприймайте все на цій сторінці зі скепсисом і перевіряйте дати комітів репозиторію, перш ніж довіряти.

Давній вердикт спільноти, закріплений для новачків ще з 2025-го: *«Облиш надію, кожен, хто сюди входить. Драйверів Windows не буде з імовірністю 99.5%. Без драйвера ця плата майже повністю марна. Драйвер Linux існує — якщо ви не готові до тієї ОС, ця плата вам не потрібна.»* ([src](https://t.me/c/2424231195/28109))

Це був консенсус понад рік. 2026-го його **нарешті почали оскаржувати** — але повільно, і чесна відповідь усе ще: ще ні.

## Чому Windows тут складна (стіна Code 43)

APU BC-250 («Cyan Skillfish» / Oberon, GFX10.1.3) подає себе ОС як **невідомий пристрій** — PCI ID `1002:13FE` — який не розпізнає жоден поставлений драйвер AMD. Люди пробували все:

- **Силоміць згодувати офіційний `.inf`** диспетчеру пристроїв: єдиний драйвер, який Windows пропонує як «сумісний», — це **Radeon Pro W5700**. Він встановлюється, потім зависає на **Error 43**, точно як і кожен інший випробуваний драйвер. ([src](https://t.me/c/2424231195/57123))
- **Редагування `.inf` / підміна ID пристроїв** (gfx1013, 1014, Navi 21/22/23 «Dragonball», legacy-записи), вимкнення примусу підпису драйверів, навіть завантаження Windows 10 з USB і спроба драйвера Steam Deck — **усе глухі кути**. Legacy-записи з'являються без помилки лише через баг відображення, а не тому, що працюють. ([src](https://t.me/c/2424231195/94029))
- **Модінг BIOS** для зміни ID пристрою теж не допоміг — iGPU все одно повідомляє `1002:13FE`. Dev ID, схоже, **вварений в APU**, а не лише в BIOS, тож патчити одне місце недостатньо. ([src](https://t.me/c/2424231195/57123))

Чому Linux працює, а Windows ні? У Linux відкритий стек **amdgpu/Mesa** був пропатчений спільнотою (і частково потрапив в апстрим), щоб розпізнавати саме цей чип; у Windows немає відкритого драйвера, який можна пропатчити — AMD ніколи не випускала драйвер Windows для цієї майнінгової/серверної деталі, а закритий стек Adrenalin/Pro відмовляє невідомому ID. ([src](https://t.me/c/2424231195/13210)) Власна гілка AMD на форумі про «драйвери BC-250» нічим не закінчилася. ([community.amd.com](https://community.amd.com/t5/pc-drivers-software/bc-250-drivers/td-p/671692))

> **Запасного виходу через GPU-passthrough теж немає.** Запуск Windows у ВМ із прокинутою BC-250 не працює: шлях IOMMU-passthrough на цій платі зламаний, і це *APU* (а не дискретна карта, яку хост може чисто передати), а ще чип від початку хибно визначається як невідомий пристрій. ([src](https://t.me/c/2424231195/64772))

## Поточний стан драйверів — що насправді існує (станом на початок 2026)

Наприкінці 2025-го спільнота припинила чекати на AMD і почала **будувати драйвер Windows з нуля**, реверс-інжинірячи залізо. Важать дві спроби; обидві **експериментальні, WIP, і ще не рендерять ігри.**

### Keshas-dev — WDDM-драйвер з нуля (найактивніший)

Пара драйверів режиму ядра, що працюють у парі, — найактивніше розроблювана спроба під Windows (**самих комітів драйвера PSP ~56** на момент написання):

- **[Keshas-dev/AMD-BC-250-PSP-Driver](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver)** — низькорівневий драйвер для **PSP** (Platform Security Processor). **Що працює:** він завантажується, піднімає прошивку **SOS**, читає/пише апаратні регістри через BAR5 MMIO (блоки GC, MMHUB, HDP, NBIO, DF), робить розблокування NBIO й виступає проксі регістрів для драйвера GPU. **Що не працює:** створення кільця GPCOM (прошивка SOS не підтримує протокол кільця TOS), завантаження прошивки GPU через кільцевий буфер та ініціалізація Trusted Memory Region. Інакше кажучи: він може говорити з чипом, але **ще не може підняти графічний движок.** ([repo](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver/commits/main/))
- **[Keshas-dev/AMD-BC-250-Windows-Driver](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver)** — парний драйвер GPU. Поділяє ту саму інфраструктуру сертифіката/тестового підпису, що й драйвер PSP, і використовує його як міст регістрів. Усе ще рано; немає придатного 3D-виводу. ([repo](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver/commits/main/))

Перша публічна ознака життя — учасник, який повідомив про **«мій перший робочий драйвер (OpenGL 1.1)»** у жовтні 2025 ([src](https://t.me/c/2424231195/83320)) — її святкували саме тому, що навіть ледь функціональний драйвер, який *встановлюється й запускається*, був реальною віхою після року Code 43: *«якщо цей драйвер справді встановився й працює (хай навіть погано) — це величезний крок.»* ([src](https://t.me/c/2424231195/83332)) Дамп драйвера з тієї хвилі, `AMD Radeon BC-250 (Cyan Skillfish) driver 00.00.01.7z`, поширили/закріпили в чаті. ([src](https://t.me/c/2424231195/83322)) **Сприймайте будь-який такий ранній дамп як експериментальний — версія `00.00.01` рівно настільки сира, як і звучить.**

### ZEROAESQUERDA — еталонна реалізація WDDM 2.0

**[ZEROAESQUERDA/BC250-windowsDriverTest](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest)** — окрема спроба («португалець щось почав»), закріплена в чаті в березні 2026 як ознака, що крига скресає. ([src](https://t.me/c/2424231195/123644)) Її найкраще розуміти як **довідкову/освітню реалізацію WDDM 2.0**, а не придатний драйвер:

- Реалізує лише **DDI Direct3D 9**; **D3D11, D3D12 і Vulkan не реалізовані.**
- **Компіляція шейдерів для RDNA2 (ISA GFX10.1) не функціонує** — він приймає подачу шейдерів, але не може скомпілювати їх під реальне залізо, тож нічого не рендериться.
- **Не** завантажує мікрокод командного процесора (покладається на прошивку, завантажену BIOS); **відео-кодек/декодек VCN не підтримується**; лише один вихід DisplayPort.
- Потребує **режиму тестового підпису** (без підпису WHQL). Лише ~2 коміти в main.

Перегляньте власний розділ проєкту **[Known Limitations](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest?tab=readme-ov-file#15-limita%C3%A7%C3%B5es-conhecidas)**, перш ніж витрачати на нього час.

> ⚠ **Виправлення назви репозиторію.** Головний список репозиторіїв вказує на `ZEROAESQUERDA/PS5GPU-BC250` під «Drivers → Windows». Під час перевірки виявляється, що цей репозиторій — **губернатор GPU для Linux** (форк Oberon-губернатора з GUI), а **не** драйвер Windows. Реальний код Windows цього автора — **`BC250-windowsDriverTest`**.

### Стан з першого погляду

| Проєкт | Тип | Що працює | Що не працює | Користуватися сьогодні? |
|---|---|---|---|---|
| Keshas-dev/AMD-BC-250-PSP-Driver | Драйвер ядра PSP (WIP) | Піднімає прошивку SOS, R/W регістрів BAR5, розблокування NBIO, проксі регістрів | Створення кільця GPU, завантаження FW, ініціалізація TMR | Ні — лише обв'язка |
| Keshas-dev/AMD-BC-250-Windows-Driver | Драйвер GPU (WIP) | Завантажується поруч із драйвером PSP | Немає придатного 3D | Ні |
| ZEROAESQUERDA/BC250-windowsDriverTest | Довідник WDDM 2.0 | Каркас моделі драйвера, присутній DDI D3D9 | Компіляція шейдерів, D3D11/12, Vulkan, VCN | Ні — освітній |
| Adrenalin / Pro / `.inf` W5700 | Офіційний AMD | — | **Code 43**, нічого | Ні |

**Підсумок:** ніхто сьогодні не грає в ігри під Windows на BC-250. Робота реальна й прискорюється, але вона на стадії «чи зможемо ми взагалі ініціалізувати GPU», а не на стадії «який у мене FPS у Cyberpunk».

## Якщо ви все ж хочете спробувати WIP-драйвери

Це для ентузіастів, які хочуть **допомогти з тестуванням**, а не для отримання робочого десктопа. Вам знадобиться:

- **Windows 10 (build 1607+) або Windows 11, x64.**
- **Увімкнений тестовий підпис** і **вимкнений Secure Boot** (ці драйвери непідписані/тестово-підписані):
  ```
  bcdedit /set testsigning on
  ```
  Перезавантажте. ⚠ перевірте — точні кроки наведені в README кожного репозиторію; команди тут — це стандартний потік тестового підпису WDK, а не скопійовані зі скрипту проєкту.
- Встановіть через наданий репозиторієм **PowerShell-скрипт** (наприклад, `Install-Driver.ps1`) або вручну через `pnputil`. Дотримуйтеся **README репозиторію**, а не цієї сторінки — ці проєкти швидко змінюються, і кроки встановлення рухаються разом із ними.

Очікуйте: у найкращому разі пристрій перелічується й з'являються логи ранньої ініціалізації; у найгіршому — нічого не змінюється або ви отримуєте інший код помилки. **Зробіть резервну копію всього, що вам цінне, і вважайте, що воно не рендеритиме.**

### ⚠ Неперевірена чутка: «злив драйверів окирпичує плату»

Під час ранньої фази бета-тесту 2025-го учасник попередив, що **BC-250 віддалено окирпичували за злив передрелізних драйверів** — стверджуючи про повідомлення на Reddit про окирпичення, віддалені блокування пристроїв і про те, що навіть апаратний програматор не міг їх розблокувати. ([src](https://t.me/c/2424231195/26231)) **Ми не змогли це перевірити**, і вся обгортка «приватної бети» навколо цього сумнівна (див. наступний розділ). Згадано для повноти; не сприймайте це як встановлений факт. Якщо ви окирпичили плату з не пов'язаних причин — див. [08-bios.md](../en/08-bios.md) щодо відновлення.

## Містифікації, жарти та глухі кути — не ведіться на них

Хайп навколо драйверів Windows для BC-250 має довгу історію **розіграшів і прийняття бажаного за дійсне**. Знайте найвідоміші, щоб не змарнувати вихідні:

- **«NVIDIA-драйвер для AMD BC-250».** Жарт на **День сміху (1 квітня 2026)** — глянцевий фейковий банер «NVIDIA NEW DRIVER RELEASE … for AMD BC-250», який ненадовго змусив людей питати *«невже NVIDIA справді випустила драйвер Windows для BC-250?!»* ([src](https://t.me/c/2424231195/130053)) Ні. NVIDIA не робить драйверів для APU AMD. Реакція в чаті була *«довгоочікуваний жарт прибув».* ([src](https://t.me/c/2424231195/130727)) Також зверніть увагу: ходив `.exe` з назвою на кшталт `whql-amd-software-adrenalin-edition-25.5.1-...-bc250.exe` — звичайний інсталятор Adrenalin із приліпленим до імені файлу «bc250» **не** робить його драйвером BC-250. ([src](https://t.me/c/2424231195/73924))
- **«Просто примусово встанови драйвер схожої карти».** RX 6700 / W5700 / Radeon Pro V340 — перша ідея кожного новачка, і вона спадала на думку *«кожному дурню, який тримав BC-250 у руках».* Вона не може спрацювати з купи причин, які не варто виводити заново: **немає драйверів Windows, немає честі й немає пива на BC-250.** ([src](https://t.me/c/2424231195/29710))
- **Шкідливе ПЗ в каналі.** Люди постили фейкові «драйвери», які були вірусами/zip-бомбами/фішерами. Моди банять на місці; колись з'явився файл, буквально названий `Trojan.txt`. ([src](https://t.me/c/2424231195/49668)) **Запускайте бінарники лише з названих репозиторіїв GitHub і читайте код.**

## А що з тим скриптом розблокування 40 CU, який люди згадують?

`git clone https://github.com/duggasco/bc250-40cu-unlock.git` випливає в розмовах на тему Windows, і навіть головний список ресурсів тегує його під «Windows». **Це патч/скрипт ядра `amdgpu` для Linux** (`bc250-enable-40cu.sh`), а не інструмент Windows — він розблоковує всі 40 CU на драйвері Linux. Він належно описаний у [09-overclock-undervolt.md](../en/09-overclock-undervolt.md); для Windows він не робить нічого. ⚠ перевірте (жодна історія команд із корпусу Command не підтверджує використання під Windows; єдина зафіксована команда — простий `git clone` вище).

| Ви хочете… | Зробіть це |
|---|---|
| Грати в ігри / реально користуватися платою зараз | **Встановіть Linux.** Див. [06-linux.md](../en/06-linux.md). Робочий драйвер GPU існує лише там. |
| Стежити за / зробити внесок у роботу над Windows | Слідкуйте за **Keshas-dev** (драйвери PSP + GPU) і **ZEROAESQUERDA/BC250-windowsDriverTest**; очікуйте роботу з ядром/WDK, а не ігри. |
| Чарівний `.inf` чи драйвер «схожої карти» | Такого немає. Зупиніться тут — ви лише впретеся в Code 43. |

Підтримка Windows — це **рухома ціль**: перечитайте дати комітів репозиторіїв і дату цього розділу (він відображає **початок 2026**), перш ніж діяти. Вердикт 2025-го був «ніколи»; 2026-й знизив це до «ще ні» — реальний прогрес, але прогрес на рівні ініціалізації прошивки, а не грабельного десктопа.
