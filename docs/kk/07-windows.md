# Windows драйверлері және орнату

> **TL;DR** — **2026 жылдың басындағы жағдай бойынша BC-250 үшін жұмыс істейтін Windows GPU драйвері жоқ.** Windows орнатылады әрі жүктеледі, бірақ GPU **Code 43**-пен тұрып қалады әрі 3D-үдетуі нөл — дайын кез келген AMD драйверін (Adrenalin, Pro, W5700 `.inf` айласы) аппаратура қабылдамайды. Қауымдастық **оны нөлден кері инженерлеп** жасап жатыр, ал шынайы жағдай: «алғашқы құбыр өткізу жұмыс істейді, бірақ әлі ешбір ойын рендерленбейді». Бұл тақтаны бүгін шынымен *қолданғыңыз* келсе — **Linux орнатыңыз** ([06-linux.md](06-linux.md)) — жұмыс істейтін драйвер сонда тұр. Бұл беттегінің бәріне күмәнмен қараңыз әрі сенерден бұрын репозиторийдегі коммит күндерін тексеріңіз.

Жаңадан келгендерге 2025 жылдан бері бекітіліп қойылған, қауымдастықтың баяғы үкімі: *«Мұнда кіргендер, бар үмітіңізді тастаңыздар. Windows драйверлері 99,5% ықтималдықпен болмайды. Драйверсіз бұл тақта дерлік мүлдем пайдасыз. Linux драйвері бар — егер сіз ол ОЖ-ге дайын болмасаңыз, бұл тақта сізге қажет емес.»* ([src](https://t.me/c/2424231195/28109))

Бұл бір жылдан астам уақыт бойы консенсус болды. Ол 2026 жылы ақыры **дауланып жатыр** — бірақ баяу, ал шынайы жауап әлі де сол: әзірге жоқ.

## Мұнда Windows неге қиын (Code 43 қабырғасы)

BC-250 APU («Cyan Skillfish» / Oberon, GFX10.1.3) өзін ОЖ-ге **белгісіз құрылғы** ретінде — PCI ID `1002:13FE` — таныстырады, оны бірде-бір шығарылған AMD драйвері танымайды. Адамдар бәрін көріп шықты:

- **Ресми `.inf`-ті Құрылғы менеджеріне зорлап тықпалау**: Windows «үйлесімді» деп ұсынатын жалғыз драйвер — **Radeon Pro W5700**. Ол орнатылады, содан **Error 43**-те тұрып қалады, дәл сыналған барлық басқа драйвер сияқты. ([src](https://t.me/c/2424231195/57123))
- **`.inf`-ті өңдеу / құрылғы ID-ларын ауыстыру** (gfx1013, 1014, Navi 21/22/23 «Dragonball», ескі жазбалар), драйвер қолтаңбасын мәжбүрлеп өшіру, тіпті Windows 10-ды USB-дан жүктеп Steam Deck драйверін көру — **бәрі тұйық**. Ескі жазбалар қатесіз көрінеді, бірақ ол жұмыс істегендіктен емес, көрсету қателігінен. ([src](https://t.me/c/2424231195/94029))
- **Құрылғы ID-ын өзгерту үшін BIOS-ты моддтау** да көмектеспеді — iGPU әлі де `1002:13FE` деп хабарлайды. Dev ID **APU-ге пісіріліп біткен** сияқты, тек BIOS-қа ғана емес, сондықтан бір орынды патчтау жеткіліксіз. ([src](https://t.me/c/2424231195/57123))

Linux неге жұмыс істейді, ал Windows жұмыс істемейді? Linux-та ашық бастапқы кодты **amdgpu/Mesa** стегін қауымдастық осы дәл чипті тану үшін патчтады (әрі ішінара жоғарыға енгізді); Windows-та патчтайтын ашық драйвер жоқ — AMD бұл майнинг/сервер бөлшегіне Windows драйверін ешқашан шығармаған, ал жабық Adrenalin/Pro стегі белгісіз ID-ды қабылдамайды. ([src](https://t.me/c/2424231195/13210)) AMD-нің өз форумындағы «BC-250 драйверлері» тақырыбы еш жерге апармады. ([community.amd.com](https://community.amd.com/t5/pc-drivers-software/bc-250-drivers/td-p/671692))

> **GPU passthrough түріндегі құтылу жолы да жоқ.** BC-250-ді өткізіп берген VM-да Windows-ты іске қосу жұмыс істемейді: бұл тақтада IOMMU passthrough жолы бұзылған, әрі бұл — *APU* (хост таза тапсыра алатын бөлек карта емес), әрі чип бастапқыда белгісіз құрылғы ретінде қате анықталады. ([src](https://t.me/c/2424231195/64772))

## Қазіргі драйвер статусы — нақты не бар (2026 жылдың басындағы жағдай бойынша)

2025 жылдың аяғында қауымдастық AMD-ні күтуді доғарып, аппаратураны кері инженерлеу арқылы **нөлден Windows драйверін жасай** бастады. Екі әрекет маңызды; екеуі де **эксперименттік, WIP, әрі әлі ешбір ойынды рендерлемейді.**

### Keshas-dev — нөлден жасалған WDDM драйвері (ең белсенді)

Бір-бірін толықтыратын екі ядро режиміндегі драйвер, ең белсенді дамытылатын Windows әрекеті (тек **PSP драйверінде ғана осы жазылым кезінде ~56 коммит** бар):

- **[Keshas-dev/AMD-BC-250-PSP-Driver](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver)** — **PSP** (Platform Security Processor) үшін төмен деңгейлі драйвер. **Не жұмыс істейді:** ол жүктеледі, **SOS firmware**-ін жүктейді, BAR5 MMIO арқылы аппараттық регистрлерді оқиды/жазады (GC, MMHUB, HDP, NBIO, DF блоктары), NBIO unlock жасайды әрі GPU драйвері үшін регистр прокси ретінде әрекет етеді. **Не жұмыс істемейді:** GPCOM ring құру (SOS firmware TOS ring протоколын қолдамайды), ring buffer арқылы GPU-firmware жүктеу, әрі Trusted Memory Region инициализациясы. Басқаша айтқанда: ол чиппен сөйлесе алады, бірақ **графика қозғалтқышын әлі көтере алмайды.** ([repo](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver/commits/main/))
- **[Keshas-dev/AMD-BC-250-Windows-Driver](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver)** — оны толықтыратын GPU драйвері. PSP драйверімен бірдей сертификат/test-signing инфрақұрылымын бөліседі әрі оны регистр көпірі ретінде пайдаланады. Әлі ерте; пайдалы 3D шығысы жоқ. ([repo](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver/commits/main/))

Тіршіліктің алғашқы көпшілік белгісі — 2025 жылдың қазанында бір мүшенің **«менің алғашқы жұмыс істейтін драйверім (OpenGL 1.1)»** деп хабарлауы болды ([src](https://t.me/c/2424231195/83320)) — ол дәл сол үшін атап өтілді, өйткені бір жылдық Code 43-тен кейін тіпті әрең жұмыс істейтін драйвердің *орнатылып әрі іске қосылуы* нағыз белес еді: *«егер бұл драйвер шынымен орнатылып, жұмыс істесе (тіпті нашар болса да) — бұл үлкен қадам.»* ([src](https://t.me/c/2424231195/83332)) Сол толқыннан шыққан драйвер дампы, `AMD Radeon BC-250 (Cyan Skillfish) driver 00.00.01.7z`, чатта бөлісіліп/бекітілді. ([src](https://t.me/c/2424231195/83322)) **Кез келген осындай ерте дампты эксперименттік деп қабылдаңыз — `00.00.01` нұсқасы есту бойынша қандай шикі болса, дәл сондай.**

### ZEROAESQUERDA — WDDM 2.0 эталондық имплементациясы

**[ZEROAESQUERDA/BC250-windowsDriverTest](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest)** — бөлек әрекет («португалиялық жігіт бірдеңе бастады»), 2026 жылдың наурызында мұз қозғала бастағанының белгісі ретінде чатта бекітілді. ([src](https://t.me/c/2424231195/123644)) Оны пайдалы драйвер емес, **эталондық/оқу мақсатындағы WDDM 2.0 имплементациясы** деп түсінген жөн:

- Тек **Direct3D 9 DDI**-ды ғана имплементациялайды; **D3D11, D3D12 және Vulkan имплементацияланбаған.**
- **RDNA2 (GFX10.1 ISA) үшін шейдер компиляциясы жұмыс істемейді** — ол шейдер жіберулерін қабылдайды, бірақ оларды нақты аппаратура үшін компиляциялай алмайды, сондықтан ештеңе рендерленбейді.
- Command Processor микрокодын **жүктемейді** (BIOS жүктеген firmware-ге сүйенеді); **VCN видео кодтау/декодтау қолдау көрсетілмейді**; тек бір ғана DisplayPort шығысы.
- **test-signing режимін** талап етеді (WHQL қолтаңбасы жоқ). main-да небәрі ~2 коммит.

Оған уақыт жұмсардан бұрын жобаның өзінің **[Белгілі шектеулер](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest?tab=readme-ov-file#15-limita%C3%A7%C3%B5es-conhecidas)** бөлімін қараңыз.

> ⚠ **Репозиторий атауының түзетуі.** Негізгі репозиторий тізімі «Drivers → Windows» астында `ZEROAESQUERDA/PS5GPU-BC250`-ке сілтейді. Тексеру кезінде ол репозиторий — **Linux GPU governor** (GUI бар Oberon-governor форкі), Windows драйвері **емес**. Бұл автордан шыққан нақты Windows коды — **`BC250-windowsDriverTest`**.

## Егер сіз әлі де WIP драйверлерін көргіңіз келсе

Бұл — жұмыс істейтін жұмыс үстелін алу үшін емес, **тестілеуге көмектескісі** келетін тинкерерлерге арналған. Сізге қажет болады:

- **Windows 10 (build 1607+) немесе Windows 11, x64.**
- **Test signing қосулы** әрі **Secure Boot өшірулі** (бұл драйверлер қолтаңбасыз/test-signed):
  ```
  bcdedit /set testsigning on
  ```
  Қайта жүктеңіз. ⚠ тексеріңіз — нақты қадамдар әр репозиторийдің README-сінен кейін келеді; мұндағы командалар — стандартты WDK test-sign ағыны, жоба скриптінен көшірілген емес.
- Репозиторий ұсынған **PowerShell скрипті** арқылы (мысалы, `Install-Driver.ps1`) немесе `pnputil`-мен қолмен орнатыңыз. Бұл бетті емес, **репозиторий README-сін** ұстаныңыз — бұл жобалар тез өзгереді, ал орнату қадамдары олармен бірге жылжиды.

Күтіңіз: ең жақсы жағдайда құрылғы санамаланады әрі алғашқы инициализация логтары пайда болады; ең нашар жағдайда ештеңе өзгермейді немесе сіз басқа қате кодын аласыз. **Сізге маңызды нәрсенің бәрін сақтық көшіріп қойыңыз әрі рендерлемейді деп есептеңіз.**

### ⚠ Тексерілмеген қауесет: «драйверлерді сыртқа шығару тақтаны кірпішке айналдырады»

2025 жылдың басындағы бета-тест кезеңінде бір мүше **BC-250-лер шығарылымға дейінгі драйверлерді сыртқа шығарғаны үшін қашықтан кірпішке айналдырылып жатыр** деп ескертті — кірпішке айналдыру, құрылғыны қашықтан бұғаттау туралы Reddit хабарламаларын, тіпті аппараттық программатор да оларды құлыптан шығара алмағанын мәлімдеп. ([src](https://t.me/c/2424231195/26231)) **Біз мұны растай алмадық**, ал оны қоршаған бүкіл «жабық бета» түсіндірмесі күмәнді (келесі бөлімді қараңыз). Толықтық үшін айтылды; оны анықталған факт ретінде қабылдамаңыз. Егер тақтаны бөгде себептермен кірпішке айналдырсаңыз, қалпына келтіру үшін [08-bios.md](08-bios.md) қараңыз.

## Алдамшылар, әзілдер және тұйықтар — бұларға алданбаңыз

BC-250-дегі Windows-драйвер ажиотажында **қалжың мен қиялдың** ұзақ тарихы бар. Демалысыңызды босқа кетірмеу үшін атақтыларын біліңіз:

- **«AMD BC-250 үшін NVIDIA драйвері».** Бұл — **Сәуірдің бірі (1 сәуір 2026)** әзілі — адамдарды бір сәтке *«NVIDIA шынымен BC-250 Windows драйверін шығарды ма?!»* деп сұратқызған тып-тұйнақтай жалған «NVIDIA NEW DRIVER RELEASE … for AMD BC-250» баннері. ([src](https://t.me/c/2424231195/130053)) Шығарған жоқ. NVIDIA AMD APU-сі үшін драйвер жасамайды. Чаттағы реакция: *«көптен күткен әзіл де келді.»* ([src](https://t.me/c/2424231195/130727)) Сондай-ақ `whql-amd-software-adrenalin-edition-25.5.1-...-bc250.exe` сияқты аталған `.exe` жүзіп жүргенін ескеріңіз — файл атына «bc250» жапсырылған қалыпты Adrenalin орнатушысы оны BC-250 драйверіне айналдыр**майды**. ([src](https://t.me/c/2424231195/73924))
- **«Жай ұқсас картаның драйверін зорлап орнат».** RX 6700 / W5700 / Radeon Pro V340 — әрбір жаңадан келгеннің бірінші идеясы, әрі ол *«BC-250-ді қолына ұстаған әрбір ақымақтың»* басына келген. Ол жұмыс істей алмайды, қайта шығарудың қажеті жоқ бір топ себептермен: **BC-250-де Windows драйверлері жоқ, ар-намыс жоқ, сыра да жоқ.** ([src](https://t.me/c/2424231195/29710))
- **Арнадағы зиянды бағдарлама.** Адамдар вирус/zip-бомба/фишер болып шыққан жалған «драйверлерді» жариялады. Модераторлар көрген бойда бұғаттайды; бір рет тура `Trojan.txt` деп аталған файл пайда болды. ([src](https://t.me/c/2424231195/49668)) **Тек аталған GitHub репозиторийлерінен ғана бинарларды іске қосыңыз әрі кодты оқыңыз.**

## Адамдар айтатын 40-CU unlock скрипті ше?

`git clone https://github.com/duggasco/bc250-40cu-unlock.git` Windows тақырыбындағы әңгімеде пайда болады, ал негізгі ресурстар тізімі тіпті оны «Windows» астында белгілейді. **Бұл — Linux `amdgpu` ядро патчі / скрипті** (`bc250-enable-40cu.sh`), Windows құралы емес — ол Linux драйверінде барлық 40 CU-ды ашады. Ол [09-overclock-undervolt.md](09-overclock-undervolt.md)-да дұрыс қаралған; Windows үшін ол ештеңе істемейді. ⚠ тексеріңіз (Command-корпусының бірде-бір shell тарихы Windows-та қолданылғанын растамайды; түсіріп алынған жалғыз команда — жоғарыдағы қарапайым `git clone`).

Windows қолдауы — **қозғалмалы нысана**: әрекеттен бұрын репозиторийдегі коммит күндерін әрі осы бөлімнің күнін (бұл **2026 жылдың басын** көрсетеді) қайта тексеріңіз. 2025 жылғы үкім «ешқашан» еді; 2026 оны «әзірге жоқ»-қа дейін төмендетті — нағыз ілгерілеу, бірақ ойнауға жарамды жұмыс үстелі қабатында емес, firmware-инициализация қабатындағы ілгерілеу.
