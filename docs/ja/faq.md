## ハードウェアと買ったもの

**BC-250 とは結局何なのか？**
クリプトマイニング/サーバー用ボードに載った PlayStation 5 派生の APU（AMD **Cyan Skillfish** / Oberon）です: **6 コア/12 スレッドの Zen 2 CPU + 24 CU の RDNA 2 GPU + 16 GB のはんだ付け GDDR6**。グラフィックスカードでも普通の PC でもありません — PCIe スロットなし、24-pin ATX なし、見慣れた BIOS なし。[01-what-is-bc250.md](../en/01-what-is-bc250.md) を参照。

**プラグアンドプレイか？ 買うべきだったか？**
いいえ。ドライバー作業、冷却の改造、特殊な電源が必要です — いじり倒す人向けのボードです。あるベテランの言葉を借りれば、これは「一定のスキル、努力、知恵を要する」ものです。一切の手間を避けたいなら返品を。プロジェクトが好きなら、この価格帯で最も安い Linux ゲーミング / ローカル AI マシンです。[01-what-is-bc250.md](../en/01-what-is-bc250.md) を参照。

**RAM を増やせるか？**
いいえ。16 GB の GDDR6 ははんだ付けされており、CPU と GPU で共有されます。DIMM スロットはありません。選べるのは、そのプールのうち GPU が予約する量（UMA）だけで、これは改造 BIOS で設定します。[01-what-is-bc250.md](../en/01-what-is-bc250.md) と [08-bios.md](../en/08-bios.md) を参照。

**電源ボタンはあるか？**
いいえ。12 V が届いた瞬間に電源が入ります — PSU 自身のスイッチがあなたの電源ボタンです。[03-power-supply.md](../en/03-power-supply.md) を参照。

**ボードが POST しない / 箱から出してすぐブラックスクリーン — 故障？**
そうでないことが多いです。多くのボードは POST する前に **BIOS/CMOS リセット** を必要とする状態で届き、一部はヒートシンクのマウントによってわずかに **反って** 到着します — あるオーナーは紙でボードを平らにシム調整して起動しない問題を直しました。故障と断定する前にこれらを試してください。[01-what-is-bc250.md](../en/01-what-is-bc250.md) を参照。

**GPU でゲームを録画/配信できるか？**
ハードウェアではできません。ビデオエンコードブロック（VCN）が利用できないため、OBS/配信は **ソフトウェア（CPU）エンコーダー** にフォールバックします — 動作はします（Sunshine/Moonlight を使う人もいます）が、CPU と画質を犠牲にします。[01-what-is-bc250.md](../en/01-what-is-bc250.md) を参照。

**バックプレート改造用のサーマルパッドの厚さは？**
コミュニティ報告: **メモリ 2 mm、チップセット 1.5 mm**（[src](https://t.me/c/2424231195/22442)）。裏面の GDDR6 には温度センサーがないため、手探りで冷やすことになります。[04-cooling.md](../en/04-cooling.md) を参照。

## 電源

**どんな電源が必要か？**
**シングルレールの 12 V** 電源で、**PCIe 8-pin（6+2）** コネクタに **300 W 以上** を供給できるもの。よくある 3 つの道: 普通の ATX/SFX PSU（PCIe ケーブルを挿すだけ — 最も簡単）、安い中古の HP Flex 500 W サーバー PSU、または Mean Well の産業用ブリック。[03-power-supply.md](../en/03-power-supply.md) を参照。

**PSU の CPU/EPS 8-pin を使えるか？**
**いいえ — ボードを焼く可能性があります。** PCIe と CPU/EPS の 8-pin はほぼ同じに見えますが、**極性が逆** です。ボードにはセンスチェックがありません。**PCIe** ケーブルを使い、不安ならマルチメーターで確認してください。[03-power-supply.md](../en/03-power-supply.md) を参照。

**古い 750 W の PSU はワット数が十分なのに、なぜ苦戦するのか？**
古いユニットはしばしば **12 V を複数の弱いレールに分割** しており、ボードが引く約 235 W を 1 本のレールで賄えません。最新のシングルレール / DC-DC PSU か、余裕の大きいものを選んでください。[03-power-supply.md](../en/03-power-supply.md) を参照。

**電源ケーブルが熱くなった / 煙が出た。なぜ？**
ほぼ確実に **偽銅** です — 銅クラッド鋼やアルミニウムのワイヤーで、本物の銅の何倍もの抵抗を持ち、負荷で過熱します（あるメンバーの既製 PCIe スプリッターは文字通り煙を上げました）（[src](https://t.me/c/2424231195/97202)）。磁石でテストしてください: 鋼にはくっつき、銅にはくっつきません。本物の銅で **16 AWG 以上の太さ** を使ってください。[03-power-supply.md](../en/03-power-supply.md) を参照。

## 冷却

**なぜ箱から出してすぐオーバーヒート / スロットリングするのか？**
標準ヒートシンクは **パッシブ** で、マイニングラックの強制空冷トンネル向けに作られています。エアフローのない机の上では熱がこもってスロットリングします。スロットリングは約 **85 °C** で始まり、ハードリセットは約 **90 °C** です。[04-cooling.md](../en/04-cooling.md) を参照。

**実際に効く一番安い冷却の修正は？**
**密な標準フィンを薄くし**（オービタルサンダーが最速）、プリントしたシュラウド越しにフィンを通して送風する **120 mm の高静圧ファン** をボルト留めします。参考結果: Noctua NF-P12 → Furmark 約 73 °C、ゲーム 63–65 °C（[src](https://t.me/c/2424231195/42843)）。Arctic P12 Max は約 75 °C を維持（[src](https://t.me/c/2424231195/58869)）。[04-cooling.md](../en/04-cooling.md) を参照。

**なぜ高静圧ファンで、高エアフローの「ケースファン」ではないのか？**
密なフィンは高抵抗の負荷です — 高エアフローのケースファンはフィンに対して失速するだけですが、高静圧ファン（Noctua/Arctic P12）は実際に空気をフィンに *通します*。非常に密なフィンには、横並びではなく **プッシュプル（直列）** で 2 つのファンを使ってください。[04-cooling.md](../en/04-cooling.md) を参照。

**冷却が十分かどうかどう判断するか？**
**GPU と CPU を同時に** 負荷をかけ（両者は 1 つのヒートシンクを共有しています）— Furmark VK に CPU 負荷を加え — **オーバークロック状態で**（定格ではなく 2000 MHz）、負荷時に約 85 °C 未満を維持します。ピン留めされたテスト手順があります。[04-cooling.md](../en/04-cooling.md) を参照。

## Linux

**どのディストロをインストールすべきか？**
「とにかくゲームをしたい」なら、**Bazzite** をフラッシュして **`bazzite-bc250`** イメージにリベースしてください — GPU の修正が組み込まれています。マシンを学ぶなら: **Fedora**（COPR + セットアップスクリプト）または **CachyOS/EndeavourOS**（Arch）。[06-linux.md](../en/06-linux.md) を参照。

**Linux をインストールしたが、すべてが遅い / FPS が一桁。なぜ？**
GPU がアクセラレーションされていません — ソフトウェア（LLVMpipe）レンダリングになっています。**新しい Mesa（25.1+）**、**`cyan_skillfish` ファームウェアのシンボリックリンク**（またはパッチ済みパッケージ）、そして正しいカーネルパラメータが必要です。`vulkaninfo | grep deviceName` で確認してください（`llvmpipe` と表示されては *いけません*）。[06-linux.md](../en/06-linux.md) を参照。

**カーネル更新後にブラックスクリーン — どう直す？**
ほとんどのディストロでは、amdgpu がロードできるようにするファームウェアのシンボリックリンクが修正方法です:
```bash
sudo ln -s /lib/firmware/amdgpu/navi10_gpu_info.bin.zst \
           /lib/firmware/amdgpu/cyan_skillfish_gpu_info.bin.zst
```
これはカーネル更新を生き延びます（ただし **Bazzite では不可**。また firmware/amdgpu の更新で消えることがあります）（[src](https://t.me/c/2424231195/98882)）。そうでなければ古い/LTS カーネルで起動し、問題のあるカーネルをバージョン固定してください。[06-linux.md](../en/06-linux.md) を参照。

**アプリは Flatpak でインストールすべきか？**
グラフィカルなものには避けてください。Flatpak は **独自の Mesa** をバンドルし、ボードのパッチ済みのものを上書きするため、**ハードウェアアクセラレーションなし** で動きます。例えば PortProton は Flatpak ではなくターミナルからインストールする必要があります（[src](https://t.me/c/2424231195/17949)、[src](https://t.me/c/2424231195/47092)）。[06-linux.md](../en/06-linux.md) を参照。

**CPU が非力に感じる — 手軽な改善策は？**
2 つのカーネル調整: **`mitigations=off`**（CPU 脆弱性緩和を無効化）（[src](https://t.me/c/2424231195/23359)）と **`nosmt=force`**（SMT を無効化 — 軽スレッドのゲームで +15–25 % FPS だが、高ビットレートの OBS のような重いマルチタスクには悪影響）（[src](https://t.me/c/2424231195/61332)）。どちらもセキュリティ/スループットのトレードオフです。[06-linux.md](../en/06-linux.md) を参照。

**Wayland 上の GNOME/KDE が不安定 — どうすれば？**
既知の問題です。メンバーからは Wayland セッション（通常は GNOME/KDE）がこのボードで誤動作するとの報告があります。代わりに **X11 セッションを使ってください**（[src](https://t.me/c/2424231195/19623)）。[06-linux.md](../en/06-linux.md) を参照。

**RAM がすぐ一杯になる — スワップを増やせるか？**
はい、**zRAM** スワップ（圧縮 RAM スワップ）を増やしてください — コミュニティのレシピでは 32 GB に引き上げ、`/etc/systemd/zram-generator.conf` で永続化します（[src](https://t.me/c/2424231195/38703)）。実メモリは増えませんが、スパイクを吸収します。[06-linux.md](../en/06-linux.md) を参照。

**カーネル更新で壊れた — どうロールバックするか？**
システムは直近のいくつかのカーネルを保持しています。Fedora では `grubby` でそれらを一覧表示し、`grubby --set-default /boot/vmlinuz-…` してから再起動します（[src](https://t.me/c/2424231195/39393)）。迷ったら **LTS カーネル** を使ってください。[06-linux.md](../en/06-linux.md) を参照。

## Windows

**もう Windows ドライバーはあるか？**
いいえ — 2026 年初頭時点で **動作する Windows GPU ドライバーは存在しません**。Windows は起動しますが、GPU は **Code 43** で 3D なしの状態です。ゼロからのリバースエンジニアリングの取り組みが 2 つあります（Keshas-dev、ZEROAESQUERDA）が、「GPU が初期化できるか」の段階で、ゲーミングではありません。[07-windows.md](../en/07-windows.md) を参照。

**RX 6700 / W5700 のドライバーを強制インストールすればいいのでは？**
いいえ。すべての公式 `.inf`（Windows が「互換」として提示する W5700 を含む）はインストールされても Code 43 でハングします — デバイス ID `1002:13FE` が APU に溶接されているからです。これはすべての初心者が最初に思いつくアイデアですが、機能しません。[07-windows.md](../en/07-windows.md) を参照。

**GPU パススルー付きの Windows VM はどうか？**
動作しません — このボードでは IOMMU パススルーが壊れており、これは APU です（受け渡せるクリーンなディスクリートカードではありません）し、いずれにせよチップが誤検出されます。[07-windows.md](../en/07-windows.md) を参照。

**「BC-250 用 NVIDIA ドライバー」や `…bc250.exe` を見た — 本物？**
いいえ。「NVIDIA ドライバー」は **エイプリルフールのジョーク** で、ファイル名に「bc250」を付け足した Adrenalin インストーラーも、ただの普通の Adrenalin インストーラーにすぎません。名前の挙がった GitHub リポジトリのバイナリのみを実行し、コードを読んでください — 偽の「ドライバー」はマルウェアだったことがあります。[07-windows.md](../en/07-windows.md) を参照。

## BIOS と復旧

**改造 BIOS をフラッシュすべきか？**
オーバークロック/タイミング/iGPU-VRAM を解放したく、**かつ** 復旧用ハードウェアの準備ができている場合のみ。誤った設定はボードを **完全に文鎮化** させる可能性があり、このボードでは **CMOS クリアでも必ずしも復旧しません**。現行の 5.00 ベースの改造を使い、SHA-256 を検証し、Integrated Graphics は絶対に無効化しないこと（唯一の表示手段です）。[08-bios.md](../en/08-bios.md) を参照。

**文鎮化してしまった — 復旧できるか？**
通常は可能ですが、ハードウェアが必要です: **CH341A クラスの SPI プログラマー** をボードの **J4004 ヘッダー** に配線し（SOIC クリップはここでは *機能しません*）、16 MB チップを再フラッシュします。CH341A の 3.3 V データラインの罠に注意してください。[08-bios.md](../en/08-bios.md) を参照。

**VRAM 分割を変更したが、OS にはまだ古い容量が表示される。**
フラッシュ/UMA 変更の後に **CMOS をクリア** してください — CR2032 を 60 秒以上外すか、CMOS ジャンパーをショートします。一部の設定（特に VRAM/UMA）は、これをしないと適用されません（[src](https://t.me/c/2424231195/97290)）。[08-bios.md](../en/08-bios.md) を参照。

## オーバークロックとアンダーボルト

**どうオーバークロックするか？ やる価値はあるか？**
**governor** を動かし（多くのビルドは **oberon-governor** を使用）、GPU を **2000 MHz** に向けて引き上げます（*GPU バウンド時* に約 +30 % FPS）。新しい `bc250_smu_oc` は CPU もオーバークロックします（約 4 GHz @ 1275 mV）。**先にボードを冷やすこと** — 約 90 °C を超える OC はリセットします。[09-overclock-undervolt.md](../en/09-overclock-undervolt.md) を参照。

**40-CU 解放とは何か？**
ダイには物理的に **40 CU** がありますが、ファームウェアは **24** のみをアクティブにしています。パッチ済みの amdgpu + `amdgpu.bc250_cc_write_mode=3` で全 40 を再有効化します — クロックよりも大きな GPU の伸びです（ある Superposition の実行は 4647 → 6863 になりました）。カーネルモジュールの再ビルドが必要で、Linux 専用です。[09-overclock-undervolt.md](../en/09-overclock-undervolt.md) を参照。

**どの電圧を設定すべきか？**
チップごとに異なります（シリコンの当たり外れ）。よくあるゲーム安定点: **2000 MHz ≈ 955 mV**（約 75 °C）。不安定さを隠す Furmark だけでなく、**実ゲーム + alt-tab/メニュー** で検証してください。CPU のハードリミット: **Vid は決して 1.325 V を超えないこと**。[09-overclock-undervolt.md](../en/09-overclock-undervolt.md) を参照。

**攻めすぎたアンダーボルトは危険か？**
いいえ — 最悪でもボードが落ちるか M.2 スロットが無効になる程度で、OC は BIOS に保存されないため数秒でクリアされます。危険なのは CPU を *過剰に* 昇圧する方向です。[09-overclock-undervolt.md](../en/09-overclock-undervolt.md) を参照。

## ディスプレイ、WiFi、Bluetooth

**HDMI で映像が出ない？**
ボードは **DisplayPort** で出力します。HDMI/TV には **DP→HDMI アダプターまたはケーブル** を使ってください（良いものは BIOS でも動作し 4K も出ます）（[src](https://t.me/c/2424231195/24107)）。安いパッシブアダプターより、本物の **DP→HDMI ケーブル** を選んでください — 粗悪なアダプターはあるメンバーにブラックスクリーンを引き起こしました（[src](https://t.me/c/2424231195/96416)）。

**DisplayPort 経由の音声が歪む。**
Linux での既知の問題です。簡単な修正は **DP→HDMI** アダプター経由で出力することで、これはクリーンな音声を伝送します（[src](https://t.me/c/2424231195/17953)）。[01-what-is-bc250.md](../en/01-what-is-bc250.md) を参照。

**WiFi/Bluetooth はあるか？**
オンボードのワイヤレスはありません — **USB ドングル** が必要で、ブランドではなく **チップセット** で選びます。最も文書化されているのは **aic8800d80** のスティックです。安い Realtek RTL8821/8822 のスティックは `lwfinger/rtw88` で動きますが、負荷時に切断されます。セットアップには、有線の USB-Ethernet アダプターが問題ごと回避できます。[10-wifi-bt.md](../en/10-wifi-bt.md) を参照。

**WiFi ドングルが切断され続ける。**
BC-250 上の Realtek の典型的な症状です: 正しいツリー外ドライバー（rtw88 / rtl8831）をインストールし、背面の USB ポートを試し、抜き差しではなく `usbreset` でリセットします。価格より信頼性が重要なら、aic8800d80 または実績のある Digma スティックに切り替えてください。[10-wifi-bt.md](../en/10-wifi-bt.md) を参照。

## ゲーミングと AI

**どのくらいの FPS が期待できるか？**
実効 **2000 MHz** の OC で: 最新の AAA は **40–60 FPS**、軽い/古いゲームは 60 超。**1080p–1440p** で FSR を使うのが最適です。ボードは通常 **CPU バウンド** なので、解像度はしばしば「無料」ですが、物理演算が重い/スレッド化の悪いゲームは何をしてもカクつきます。[11-gaming.md](../en/11-gaming.md) を参照。

**どのゲームが一番よく動くか？**
**ファーストパーティの PlayStation 移植** （God of War、Horizon、The Last of Us、Spider-Man、Ghost of Tsushima）— GPU に頼り、最適化が良好です。エミュレーション: Switch（Eden）と PS4（shadPS4）は堅実。Xbox 360（Xenia）はだめです。[11-gaming.md](../en/11-gaming.md) を参照。

**GPU 負荷が約 40 % なのに FPS が低いのはなぜ？**
**CPU バウンド** です — ボトルネックは GPU ではなく 6 コアの Zen 2 です。その場合アップスケーリングでは FPS はあまり上がりません。`nosmt=force`/`mitigations=off` を試し、一部のタイトルは CPU 制限であることを受け入れてください。[11-gaming.md](../en/11-gaming.md) を参照。

**ローカル LLM / AI を動かせるか？**
はい — 16 GB の GDDR6 は、`llama.cpp`/Jan を **Vulkan** バックエンドで使って中規模モデルを保持できます。まず BIOS で GPU に約 12 GB を割り当てるよう設定してください。[12-ai-llm.md](../en/12-ai-llm.md) を参照。

## 購入

**適正価格と、どこで買うか？**
価格と入手先は変動が速く、地域依存です（eBay、AliExpress、CIS では Ozon/Avito）— 最近の報告は 100 ドル台前半から約 13,000 ルーブルあたりに集中しています。[02-buying.md](../en/02-buying.md) を参照。

**1 台買うリスクは？**
これは中古のマイニング/サーバーハードウェアです: ボードは BIOS リセットを要する状態、わずかに反った状態、ときには不良で届くことがあり、ベンダーサポートはありません — コミュニティがあなたのサポートです。お金だけでなく時間も確保してください。[01-what-is-bc250.md](../en/01-what-is-bc250.md) と [02-buying.md](../en/02-buying.md) を参照。

**macOS を動かせるか？**
やめてください。CPU は起動するかもしれませんが、**GPU は決してアクセラレーションしません**（なりすませる対応ペアがなく、AMD APU の iGPU が macOS で動作したことは一度もありません）。Linux を使ってください。[13-macos.md](../en/13-macos.md) を参照。
