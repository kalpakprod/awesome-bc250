# Windows ドライバーとセットアップ

> **要点** — **2026 年初頭時点で、BC-250 向けに動作する Windows GPU ドライバーは存在しません。** Windows はインストールできて起動もしますが、GPU は **Code 43** のまま止まり、3D アクセラレーションはゼロです — 市販の AMD ドライバー（Adrenalin、Pro、W5700 の `.inf` トリック）はすべてハードウェアに拒否されます。コミュニティは **ゼロからリバースエンジニアリング** で作っている最中であり、正直な状況は「初期の配管は動くが、まだゲームは何も描画できない」です。このボードを今日 *実際に使いたい* なら、**Linux をインストールしてください**（[06-linux.md](../en/06-linux.md)）— 動作するドライバーはそこにあります。このページの内容はすべて懐疑的に扱い、信頼する前にリポジトリのコミット日付を確認してください。

長年のコミュニティの結論は、2025 年以降、新規参入者向けにピン留めされてきました。*「ここに入る者よ、いっさいの希望を捨てよ。Windows ドライバーは 99.5% の確率で実現しません。ドライバーがなければこのボードはほぼ完全に役立たずです。Linux ドライバーは存在します — その OS を受け入れる準備がないなら、このボードは必要ありません。」* ([src](https://t.me/c/2424231195/28109))

それが 1 年以上のあいだコンセンサスでした。2026 年に **ついにそれが覆されつつあります** — ただしゆっくりとであり、正直な答えはやはり「まだ」です。

## ここで Windows が難しい理由（Code 43 の壁）

BC-250 APU（「Cyan Skillfish」/ Oberon、GFX10.1.3）は、OS に対して **不明なデバイス** として認識されます — PCI ID `1002:13FE` — これを認識する出荷済み AMD ドライバーは存在しません。人々はあらゆる手を試してきました：

- **公式の `.inf` をデバイスマネージャーに無理やり食わせる**：Windows が「互換」として提示する唯一のドライバーは **Radeon Pro W5700** です。インストールはできますが、他のすべての試みと同様、**Error 43** でハングします。 ([src](https://t.me/c/2424231195/57123))
- **`.inf` の編集 / デバイス ID の差し替え**（gfx1013、1014、Navi 21/22/23「Dragonball」、レガシーエントリ）、ドライバー署名の強制の無効化、さらには Windows 10 を USB から起動して Steam Deck のドライバーを試すことまで — **すべて行き止まり** です。レガシーエントリがエラーなしで表示されるのは、それが動作するからではなく、表示上のバグによるものにすぎません。 ([src](https://t.me/c/2424231195/94029))
- **BIOS を改造してデバイス ID を変える** のも役に立ちませんでした — iGPU はやはり `1002:13FE` を報告します。Dev ID は BIOS だけでなく **APU に溶接されている** ように見えるため、一箇所だけパッチを当てても不十分です。 ([src](https://t.me/c/2424231195/57123))

なぜ Linux は動いて Windows は動かないのか？ Linux ではオープンソースの **amdgpu/Mesa** スタックが、まさにこのチップを認識するようコミュニティによってパッチされました（一部はアップストリームにも取り込まれています）。Windows にはパッチを当てるオープンドライバーが存在しません — AMD はこのマイニング/サーバー部品向けに Windows ドライバーを一度も出荷しておらず、クローズドな Adrenalin/Pro スタックは不明な ID を拒否します。 ([src](https://t.me/c/2424231195/13210)) AMD 自身の「BC-250 ドライバー」に関するフォーラムスレッドは何の進展もありませんでした。 ([community.amd.com](https://community.amd.com/t5/pc-drivers-software/bc-250-drivers/td-p/671692))

> **GPU パススルーという逃げ道もありません。** BC-250 をパススルーした VM で Windows を動かすのは機能しません：このボードでは IOMMU パススルー経路が壊れており、しかもこれは *APU*（ホストがきれいに引き渡せる単体カードではない）であり、そもそもチップが不明なデバイスとして誤検出されます。 ([src](https://t.me/c/2424231195/64772))

## 現在のドライバー状況 — 実際に存在するもの（2026 年初頭時点）

2025 年後半、コミュニティは AMD を待つのをやめ、ハードウェアをリバースエンジニアリングして **ゼロから Windows ドライバーを作り始めました**。重要な取り組みは 2 つあり、どちらも **実験的で、開発中（WIP）であり、まだゲームを描画できません。**

### Keshas-dev — ゼロから作る WDDM ドライバー（最も活発）

カーネルモードドライバーのペア（コンパニオン）で、最も活発に開発されている Windows の取り組みです（本稿執筆時点で **PSP ドライバーだけで約 56 コミット** あります）：

- **[Keshas-dev/AMD-BC-250-PSP-Driver](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver)** — **PSP**（Platform Security Processor）向けの低レベルドライバーです。**動くもの：** ロードでき、**SOS ファームウェア** を起動し、BAR5 MMIO 越しにハードウェアレジスタを読み書きし（GC、MMHUB、HDP、NBIO、DF ブロック）、NBIO のアンロックを行い、GPU ドライバーのレジスタプロキシとして機能します。**動かないもの：** GPCOM リング作成（SOS ファームウェアは TOS リングプロトコルに非対応）、リングバッファ経由の GPU ファームウェアロード、Trusted Memory Region の初期化。言い換えると、チップとは会話できるが、**まだグラフィックスエンジンを立ち上げられません。** ([repo](https://github.com/Keshas-dev/AMD-BC-250-PSP-Driver/commits/main/))
- **[Keshas-dev/AMD-BC-250-Windows-Driver](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver)** — コンパニオンの GPU ドライバーです。PSP ドライバーと同じ証明書/テスト署名インフラを共有し、それをレジスタブリッジとして使います。まだ初期段階で、使える 3D 出力はありません。 ([repo](https://github.com/Keshas-dev/AMD-BC-250-Windows-Driver/commits/main/))

最初の公開された生存の兆候は、あるメンバーが 2025 年 10 月に **「初めて動作したドライバー（OpenGL 1.1）」** を報告したことでした ([src](https://t.me/c/2424231195/83320)) — これがまさに称賛されたのは、辛うじて機能するだけのドライバーであっても *インストールされて動くこと* が、1 年に及ぶ Code 43 の後では本物のマイルストーンだったからです：*「このドライバーが本当にインストールされて（たとえ不出来でも）動くなら、それは大きな一歩だ。」* ([src](https://t.me/c/2424231195/83332)) その波で出たドライバーダンプ `AMD Radeon BC-250 (Cyan Skillfish) driver 00.00.01.7z` がチャットで共有/ピン留めされました。 ([src](https://t.me/c/2424231195/83322)) **このような初期ダンプはすべて実験的なものとして扱ってください — バージョン `00.00.01` は、その名のとおり生のままです。**

### ZEROAESQUERDA — WDDM 2.0 のリファレンス実装

**[ZEROAESQUERDA/BC250-windowsDriverTest](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest)** — 別の取り組み（「ポルトガルの人が何かを始めた」）で、氷が割れ始めた兆しとして 2026 年 3 月にチャットでピン留めされました。 ([src](https://t.me/c/2424231195/123644)) これは使えるドライバーではなく、**リファレンス/教育用の WDDM 2.0 実装** と理解するのが最善です：

- **Direct3D 9 DDI** のみを実装しています。**D3D11、D3D12、Vulkan は未実装です。**
- **RDNA2（GFX10.1 ISA）向けのシェーダーコンパイルは機能しません** — シェーダーの送信は受け付けますが、実際のハードウェア向けにコンパイルできないため、何も描画されません。
- Command Processor のマイクロコードを **ロードしません**（BIOS がロードしたファームウェアに依存）。**VCN のビデオエンコード/デコードは非対応**。DisplayPort 出力は 1 つのみ。
- **テスト署名モード** が必要です（WHQL 署名なし）。main にはコミットが約 2 件のみ。

時間を費やす前に、プロジェクト自身の **[Known Limitations](https://github.com/ZEROAESQUERDA/BC250-windowsDriverTest?tab=readme-ov-file#15-limita%C3%A7%C3%B5es-conhecidas)** セクションを参照してください。

> ⚠ **リポジトリ名の訂正。** メインのリポジトリ一覧は「Drivers → Windows」の下で `ZEROAESQUERDA/PS5GPU-BC250` を指しています。調べてみると、そのリポジトリは **Linux GPU governor**（GUI 付きの Oberon-governor フォーク）であり、**Windows ドライバーではありません**。この作者による実際の Windows コードは **`BC250-windowsDriverTest`** です。

### ひと目でわかる状況

| プロジェクト | 種類 | 動くもの | 動かないもの | 今日使える？ |
|---|---|---|---|---|
| Keshas-dev/AMD-BC-250-PSP-Driver | PSP カーネルドライバー（WIP） | SOS ファームウェア起動、BAR5 レジスタ R/W、NBIO アンロック、レジスタプロキシ | GPU リング作成、FW ロード、TMR 初期化 | いいえ — 配管のみ |
| Keshas-dev/AMD-BC-250-Windows-Driver | GPU ドライバー（WIP） | PSP ドライバーと並んでロード | 使える 3D なし | いいえ |
| ZEROAESQUERDA/BC250-windowsDriverTest | WDDM 2.0 リファレンス | ドライバーモデルの足場、D3D9 DDI あり | シェーダーコンパイル、D3D11/12、Vulkan、VCN | いいえ — 教育用 |
| Adrenalin / Pro / W5700 `.inf` | 公式 AMD | — | **Code 43**、何もなし | いいえ |

**結論：** 今日、Windows 上の BC-250 でゲームをしている人は誰もいません。作業は本物で加速していますが、「GPU を初期化できるのか」という段階であって、「私の Cyberpunk の FPS はいくつか」という段階ではありません。

## それでも開発中（WIP）のドライバーを試したいなら

これは **テストを手伝いたい** 物好き向けであって、動作するデスクトップを得るためのものではありません。必要なもの：

- **Windows 10（build 1607+）または Windows 11、x64。**
- **テスト署名を有効化** し、**Secure Boot を無効化**（これらのドライバーは未署名/テスト署名です）：
  ```
  bcdedit /set testsigning on
  ```
  再起動。⚠ 要検証 — 正確な手順は各リポジトリの README に従ってください。ここのコマンドは標準的な WDK テスト署名フローであり、プロジェクトのスクリプトからコピーしたものではありません。
- リポジトリが提供する **PowerShell スクリプト**（例 `Install-Driver.ps1`）でインストールするか、`pnputil` で手動でインストールします。このページではなく **リポジトリの README** に従ってください — これらのプロジェクトは速く変わり、インストール手順もそれに伴って動きます。

予想されること：よくてデバイスが列挙され、初期 init のログが出る程度。悪ければ何も変わらないか、別のエラーコードが出ます。**大切なものはすべてバックアップし、描画しないものと想定してください。**

### ⚠ 未検証の噂：「ドライバーを漏らすとボードが文鎮化する」

2025 年初頭のベータテスト段階で、あるメンバーが **プレリリースのドライバーを漏らしたために BC-250 がリモートで文鎮化されている** と警告しました — 文鎮化、リモートでのデバイスブロック、そしてハードウェアプログラマーでさえアンロックできなかったという Reddit の報告があると主張しました。 ([src](https://t.me/c/2424231195/26231)) **これは検証できませんでした**。そしてそれを取り巻く「プライベートベータ」という枠組み全体が疑わしいものです（次のセクションを参照）。完全性のために言及しているだけで、確立された事実として扱わないでください。無関係な理由でボードを文鎮化した場合は、復旧について [08-bios.md](../en/08-bios.md) を参照してください。

## デマ、ジョーク、行き止まり — これらに引っかからないこと

BC-250 の Windows ドライバーをめぐる誇張には、**いたずらと希望的観測** の長い歴史があります。週末を無駄にしないために、有名なものを知っておきましょう：

- **「AMD BC-250 向け NVIDIA ドライバー」。** **エイプリルフール（2026 年 4 月 1 日）** のジョークです — 「NVIDIA NEW DRIVER RELEASE … for AMD BC-250」という洗練された偽のバナーで、一時的に人々に *「NVIDIA が本当に BC-250 の Windows ドライバーを出したのか？！」* と問わせました。 ([src](https://t.me/c/2424231195/130053)) そんなことはありませんでした。NVIDIA は AMD APU 向けのドライバーを作りません。チャットでの反応は *「待ちに待ったジョークが来た」* でした。 ([src](https://t.me/c/2424231195/130727)) また、`whql-amd-software-adrenalin-edition-25.5.1-...-bc250.exe` のような名前の `.exe` が出回ったことにも注意してください — 通常の Adrenalin インストーラーのファイル名に「bc250」を付け足しただけでは、それが BC-250 ドライバーになるわけでは **ありません**。 ([src](https://t.me/c/2424231195/73924))
- **「似たカードのドライバーを無理やりインストールすればいい」。** RX 6700 / W5700 / Radeon Pro V340 — 新規参入者全員が最初に思いつくアイデアで、*「BC-250 を手にしたことのあるあらゆる愚者」* が思いついてきました。それは動きません。再導出する価値もない山ほどの理由により：**BC-250 に Windows ドライバーは、名誉も、ビールもありません。** ([src](https://t.me/c/2424231195/29710))
- **チャンネル内のマルウェア。** ウイルス/zip 爆弾/フィッシングである偽の「ドライバー」を投稿する人がいます。モデレーターは見つけ次第 BAN します。文字どおり `Trojan.txt` という名前のファイルが現れたこともあります。 ([src](https://t.me/c/2424231195/49668)) **バイナリは名前の挙がっている GitHub リポジトリのものだけを実行し、コードを読んでください。**

## 人々が言及する 40-CU 解放スクリプトはどうなのか？

`git clone https://github.com/duggasco/bc250-40cu-unlock.git` が Windows 関連の雑談に出てきて、マスターリソース一覧でさえこれを「Windows」の下にタグ付けしています。**これは Linux の `amdgpu` カーネルパッチ/スクリプト**（`bc250-enable-40cu.sh`）であって、Windows ツールではありません — Linux ドライバー上で 40 個すべての CU を解放します。これは [09-overclock-undervolt.md](../en/09-overclock-undervolt.md) で適切に扱っています。Windows に対しては何もしません。⚠ 要検証（Command コーパスのシェル履歴に Windows での使用を裏付けるものはなく、捕捉された唯一のコマンドは上記の素の `git clone` です）。

## 推奨

| あなたが望むこと… | こうする |
|---|---|
| 今ゲームをする / ボードを実際に使う | **Linux をインストール。** [06-linux.md](../en/06-linux.md) を参照。動作する GPU ドライバーはそこにしか存在しません。 |
| Windows の取り組みを追う / 貢献する | **Keshas-dev**（PSP + GPU ドライバー）と **ZEROAESQUERDA/BC250-windowsDriverTest** をウォッチ。ゲーミングではなく、カーネル/WDK の作業を見込んでください。 |
| 魔法の `.inf` や「似たカード」のドライバー | そんなものはありません。ここで止まってください — Code 43 にぶつかるだけです。 |

Windows サポートは **動く標的** です：行動する前に、リポジトリのコミット日付とこのセクションの日付（これは **2026 年初頭** を反映）を再確認してください。2025 年の結論は「実現しない」でした。2026 年はそれを「まだ」に格下げしました — 本物の進展ですが、それはファームウェア初期化のレイヤーでの進展であって、遊べるデスクトップのレイヤーではありません。
