# Стан джерел BC-250 — 2026-09-29

## Як читати цю сторінку

- Сторінка описує зріз дослідження на вказану дату, а не всі відомості про BC-250. Повнота результату стосується лише названого набору джерел і моменту завершення збору.
- **Відоме джерело Discord** — канал або гілка, чий ID уже знайдено під час дослідження. Архівна гілка з невідомим ID не входить до підрахунку Discord.
- **Закріплена ревізія** — збережена версія репозиторію. Вона не дає пізнішим змінам непомітно змінити перевірений перелік файлів.
- Сирі повідомлення спільноти й дані доступу тут не публікуються. Числа та посилання відкриті; окремі повідомлення залишаються неперевіреними до випробування на заявленому рівні.

## Оновлення — 2026-10-08

- [Розбір джерел](SOURCE_REVIEW.md) містить рішення для всіх **32 змінених файлів / 55 комітів** закріпленого upstream-delta. Це розбір патчів, не повний аудит кожного абзацу upstream і не запуск на залізі.
- У доступних недавніх знімках проскановано посилання на проєкти: **62 986 Discord / 15 925 Telegram** повідомлень із 2026-08-18; для **64 кандидатів** поза набором URL каталогу повторно отримано метадані GitHub. До тематичного каталогу додано 11 записів із підтвердженим призначенням, тепер їх **440**. Редиректи, дзеркала й спільний код не є незалежними свідченнями.
- Оновлена черга метаданих Discord містить **2694** рядки; вибірка Telegram — попередні **1067**. Повний змістовний розбір і прийняття всіх повідомлень не заявлені. Порівняння значущих форків та відхилені припущення про сумісність — у розборі.
- Свіжі авторизовані читання двох раніше недоступних каналів Discord повернули **50001 — немає доступу**. Невідомі архівні гілки неможливо вичерпно перелічити доступними інструментами; вміст вкладень і непідтверджені твердження лише з чатів залишаються відкритими. Сирі архіви та посилання з даними доступу не публікуються.
- Числа нижче зберігають початковий момент завершення збору, це не новий повний обхід платформ.

## Джерела GitHub

- Десять пошукових запитів за назвами дали 971 унікальний загальнодоступний репозиторій, зокрема 720 без зірок і 445 форків (копій інших репозиторіїв). Два незалежні обходи сторінок збіглися для цих запитів; результат не охоплює всі репозиторії, де BC-250 згадано в коді.
- Для всіх 971 репозиторію складено перелік шляхів на закріплених ревізіях: 943 містили дерево файлів, 28 були порожніми, а дерева дали 269 457 записів про шляхи. Запис указує на матеріал, але не підтверджує його роботу на платі.
- Пошук за вмістом коду знайшов щонайменше три репозиторії поза вибіркою за назвами: [`ps5-linux/ps5-linux-loader`](https://github.com/ps5-linux/ps5-linux-loader), [`KernelWanderers/OCSysInfo`](https://github.com/KernelWanderers/OCSysInfo) та [`openbsd/src`](https://github.com/openbsd/src). Це суміжні джерела, а не підтвердження сумісності з BC-250.

## Спільноти

- Історію 347 доступних відомих джерел Discord прочитано до порожньої сторінки; два джерела недоступні, а два ID некоректні. Приватний знімок містить 338 589 ID повідомлень, але невідомі архівні гілки не дають назвати архів сервера повним.
- Знімок тексту Telegram, доступного цьому обліковому запису, містить 154 621 ID повідомлень на фіксований момент завершення збору. Два незалежні способи переліку дали однаковий набір ID; видалені або закриті повідомлення та вміст вкладень не охоплено.
- Об’єднання трьох списків Reddit містить 1 441 ID дописів. В одному вибраному обговоренні отримано всі 106 коментарів, що значилися на момент перевірки; давні малопомітні дописи й решта дерев коментарів залишаються відкритими.
- Для вкладень Discord записано метадані 19 749 об’єктів. Вміст вкладень не завантажували й не перевіряли.
