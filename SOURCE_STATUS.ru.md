# Состояние источников BC-250 — 2026-09-29

## Как читать эту страницу

- Страница описывает срез исследования на указанную дату, а не все сведения о BC-250. Полнота результата относится только к названному набору источников и моменту отсечения.
- **Известный источник Discord** — канал или ветка, чей ID уже найден при исследовании. Архивная ветка с неизвестным ID не входит в подсчёт Discord.
- **Закреплённая ревизия** — сохранённая версия репозитория. Она не даёт более поздним правкам незаметно изменить проверенный список файлов.
- Сырые сообщения сообщества и данные доступа здесь не публикуются. Числа и ссылки открыты; отдельные сообщения остаются непроверенными до испытания на том уровне, о котором в них говорится.

## Источники GitHub

- Десять поисковых запросов по именам дали 971 уникальный общедоступный репозиторий, включая 720 без звёзд и 445 форков (копий других репозиториев). Два независимых обхода страниц совпали для этих запросов; результат не охватывает все репозитории, где BC-250 упомянут в коде.
- Для всех 971 репозитория составлен список путей на закреплённых ревизиях: 943 содержали дерево файлов, 28 были пустыми, а деревья дали 269 457 записей о путях. Запись указывает на материал, но не подтверждает его работу на плате.
- Поиск по содержимому кода нашёл минимум три репозитория вне выборки по именам: [`ps5-linux/ps5-linux-loader`](https://github.com/ps5-linux/ps5-linux-loader), [`KernelWanderers/OCSysInfo`](https://github.com/KernelWanderers/OCSysInfo) и [`openbsd/src`](https://github.com/openbsd/src). Это смежные источники, а не подтверждение совместимости с BC-250.

## Сообщества

- История 347 доступных известных источников Discord прочитана до пустой страницы; два источника недоступны, а два ID некорректны. Приватный снимок содержит 338 589 ID сообщений, но неизвестные архивные ветки не позволяют назвать архив сервера полным.
- Снимок доступного этому аккаунту текста Telegram содержит 154 621 ID сообщений на фиксированный момент отсечения. Два независимых способа перечисления дали одинаковый набор ID; удалённые или закрытые сообщения и содержимое вложений не охвачены.
- Объединение трёх списков Reddit содержит 1 441 ID публикаций. В одном выбранном обсуждении получены все 106 комментариев, числившихся на момент проверки; старые малозаметные публикации и остальные деревья комментариев остаются открытыми.
- Для вложений Discord записаны метаданные 19 749 объектов. Содержимое вложений не загружалось и не проверялось.
